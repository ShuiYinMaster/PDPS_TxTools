# CrossEnvIO — Process Simulate Data Transfer / 跨环境数据传输

Transfer resource trees, part trees and weld-point data between Process Simulate instances and rebuild structures in the target environment.

用于两个 Process Simulate 环境之间传输资源树、零件树和焊点数据，并在目标环境重建结构。

## 命令

- `.跨环境IO→资源/零件/焊点`

## 功能

- 枚举当前运行的 PS 实例，选择主控/被控环境。
- 将资源或零件层级导出为 TSV 结构文件，保留名称、类型、父路径和位姿。
- 导出焊点操作、焊点名称、绑定零件、位姿和父操作路径。
- 复制组件库中的 `.cojt`，并处理目标库路径与路径修复。
- 在本端或对端重建资源/零件结构和焊点；支持仅绑定已有焊点。
- 支持选择根节点、XYZ 原点偏移和导出部分焊点操作。

## 常用流程

1. 打开 `.跨环境IO→资源/零件/焊点`，刷新并选择目标 PS 实例。
2. 在资源/零件页选择根对象，识别库根并导出本端结构。
3. 按需复制 `cojt` 到对端，再在本端或对端重建。
4. 在焊点页选择操作或选择全部，导出焊点并执行目标环境重建。
5. 通过日志检查插入、复制、跳过和失败数量。

## 注意事项

- 默认导入/中转目录为统一临时根目录下的 `CrossEnvIO` 子目录，可在界面中调整。
- 对端 PS 和相关库必须可访问；组件已存在时通常会跳过复制。
- 重建会修改目标场景，`撤销复制`主要针对复制的库文件/目录，不等同于撤销全部场景修改。
- 传输前建议备份目标文档和库目录，并确认位姿偏移单位与坐标系。

## 主要文件

- `CrossEnvIOCmd.cs`、`CrossEnvIOForm.cs`：命令与界面。
- `Core/StructureIO.cs`：资源/零件结构 TSV 导出和重建。
- `Core/WeldPointIO.cs`：焊点 TSV 导出和重建。
- `Core/ComponentIO.cs`、`Core/CojtTransfer.cs`：组件插入和库文件传输。
- `Core/EnvLibrary.cs`：跨实例环境与库根发现。

## 界面与构建

跨环境窗口接入 `PickAwareTxForm`，坐标原点控件接入 `PickFocus`。资源、焊点操作及原点拾取均可用 Esc 退出并保留选择；结构导入导出与重建流程沿用现有实现。

本模块随 `TxTools.csproj` 构建。环境与注册方式见 [项目 README](../README.md)。

公共拾取实现位于 `SRC/PickFocus.cs` 和 `SRC/PickAwareTxForm.cs`；焦点回归位于独立测试目录。测试使用 SDK 控件替身和真实 WinForms 焦点/键盘消息，仍需在 PS 内确认实际拾取效果。

## 撤销与恢复（2026-10-07）

树、焊点重建及组件插入使用场景撤销分组；默认不自动覆盖并重载工程。MCP 参数 save_reload=true 才启用带原文件备份的保存/路径修补/重载。复制用独立暂存目录发布；失败目录保留清理记录，内容变化或工程引用时禁止清理。

详见 [统一撤销与恢复说明](../docs/undo-safety.md)。

## 传输一致性与恢复

- 对端实例、工程和库根绑定校验；目标失效时停止，不自动切换到其他实例。两端均需重新构建并加载新版 TxTools，远程预检使用新增的 `crossenv_inspect` 工具。
- 远程重建请求发出前保护复制文件依赖；超时或部分失败时保留文件。未重建批次的清理会核验复制目标实例与本端工程引用，以及复制后的文件清单和内容摘要。
- cojt 逐层精确映射，保留编号和版本；目标同路径已有不同内容时拒绝复用。新增 `SourceLibraryRoot` 列保留跨库相对路径；旧 TSV 同名有多份时拒绝猜测，请重新导出。
- 复制结果通过新增对象 ID 识别；复制失败、结果有歧义或重命名失败均报告错误。选中子树的根与子对象层级保持完整，新建/更新容器分别统计。
- 修正负向 90° 姿态恢复；junction 使用完整组件路径散列命名，核验真实目标，已有链接不重定向。
- 焊点多选按对象 ID 过滤。新格式 `BindPart` 为包含名称、场景相对路径和主板标记的 JSON 数组，`FormatVersion=2`；读取仍兼容旧名称和 `+` 分隔格式。同名零件按路径绑定，仅绑定模式按父操作路径定位焊点，保留独立焊点名称。
- XML 路径单次解码、单次转义，合法数值实体保持不变。psz 保留原编码和 BOM，不能表示的新路径会拒绝修改；纯 ASCII 无编码声明的条目不会被猜测后引入非 ASCII 字节。ZIP 修改在暂存副本中完成，再替换原文件，并保留独立备份。
- 导出文件先暂存再发布，失败不会把旧文件当成本次数据；远程任务使用独立快照。快照路径写入日志并保留，便于核对超时或失败任务。
- 复制 IO 在后台执行；窗口显示忙碌状态与日志进度，操作中禁用重复提交。空选择明确表示整个场景树；拾取无效对象会报错。新增导出路径选择，重置原点同时更新原生坐标控件。
- 投影、位姿设置、保存和重载失败均反馈错误；“绑定”按成功焊点计数，“新建”不再包含更新已有对象。

跨环境回归位于独立测试目录。场景逻辑使用 SDK 替身测试，真实 PS 2402 SDK 另用于编译校验；拾取、粘贴、中文路径插入和保存后重开仍需在 PS 宿主内验收。
