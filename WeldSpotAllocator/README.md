# WeldSpotAllocator — Weld Spot Allocation / 焊点分配

Update weld coordinates, map unallocated weld points to reference paths and perform symmetric weld-point allocation in Process Simulate.

TxTools 套件中的 Process Simulate 2402 插件，用于在焊接操作之间**更新焊点位置**或**分配焊点**。适用三类场景：旧版轨迹换新版坐标、把待分配焊点塞进已调好的参考轨迹、左右对称分配。

---

## 一、三种模式

打开窗口后顶部「模式（单选）」三选一，下方灰字会提示该模式的两个集合含义。

### A 位置更新
- **参考集**＝旧版焊接操作，**目标集**＝新版焊接操作。
- 作用：把旧版焊点的位置更新到新版坐标，**分配关系不变**（不新建轨迹）。
- 适用：同一批焊点出了新版坐标，要把现有轨迹里的焊点挪到新位置。

### B 新焊点分配
- **参考集**＝已分配好的参考操作，**目标集**＝待分配焊点清单（也是焊接操作）。
- 作用：为每条参考轨迹创建一条新轨迹，按选项移动或复制匹配的目标点位，并继承参考的姿态、过渡点和轨迹参数。
- 适用：新车型焊点要复用旧轨迹已调好的机器人姿态和参数。

### C 对称分配
- **参考集**＝左侧参考操作，**目标集**＝右侧待分配焊点清单（操作）。
- 作用：参考轨迹关于车身中线镜像后与右侧待分配焊点匹配，可同时镜像新轨迹中的过渡点。
- 适用：左右对称的焊点，用左侧已调好的轨迹生成右侧。

---

## 二、操作选择（参考集 / 目标集）

两个网格分别装参考集与目标集，**只接受焊接操作**，非焊接操作会被自动剔除。

- **加入对象**：点网格内的拾取行（绿色行），再去 PS 的对象树或 3D 视图里点选操作即可加入；计数会实时更新。
- **交换参考/目标**：一键对调两个网格内容（A 模式调换旧↔新方向，B/C 调换参考与待分配清单）。
- **清空列表**：清空两个网格 + 预览表。

---

## 三、匹配条件 + 分配后处理

### 匹配条件
- **焊点距离匹配** + **距离阈值 mm**：按空间距离匹配，超过阈值不配对。默认勾选，阈值 5 mm。
- **焊点名匹配**按制造焊点名称比较，忽略首尾空白和大小写。「剥前缀(名)」可从两侧去掉同一前缀，仅作用于焊点名称。
- 仅名称匹配要求规范化后的名称在两侧均唯一。预览距离仅供查看，重名会提示并跳过。A 模式在每对操作内检查重名，B/C 模式在两侧各自的全部所选轨迹内检查。
- 同时勾选名称和距离时，两项均须满足。从阈值内的同名候选中选最近的未用点。两项都取消时按距离匹配。
- **不同车件参考系**（B/C）将两侧制造焊点分别换算到各自的车件局部系，在局部系中计算距离。两侧车件可在世界坐标中分别平移和旋转。目标车件与世界系对齐时可勾选「目标使用世界坐标」。

### 参考基准

距离以制造焊点的坐标计算。B 模式在同一参考系下直接比较世界坐标。C 模式先关于参考车件的局部 XZ 平面镜像，再按同系或异系比较。不同参考系下，写入时将参考侧局部姿态（C 模式使用镜像后姿态）换算到目标侧世界系，焊接点位保留目标原平移。

可在当前工程通过原生坐标拾取框指定参考或目标车件坐标。留空时，各侧独立读取轨迹点位附着父对象的绝对位姿，随后尝试制造焊点的关联零件和附着父对象。多个关联零件的绝对位姿须一致。预览表「依据」列的提示可查看两侧基准来源。缺少换算基准时，仅名称仍可预览配对。若勾选的旋转复制或过渡点镜像缺少所需坐标，执行前会列出需补齐的条件。

### 分配后处理
- **复制旋转姿态**（B/C）默认勾选。B 复制参考轨迹点位的旋转，C 复制镜像后的旋转。两种模式均保留目标轨迹点位的平移坐标。
- **镜像翻轴(X前后/Y左右/Z上下)**（C）：镜像后焊钳绕工具自身某轴翻 180° 的修正项。焊钳坐标约定为 X＝前后、Y＝左右、Z＝上下。默认 None，需按实际枪型实测选择。
- **镜像过渡点(C)** 使用参考轨迹焊点共同的坐标基准。异系模式还需要该轨迹匹配的目标焊点共享目标侧基准，过渡点镜像后换算到目标侧世界系。
- **复制轨迹参数**（B/C）默认勾选。按名称或距离命中的点位都复制 SDK 在参考轨迹点位上公开的机器人参数及可编辑的持续时间。执行结果报告姿态和参数读回核对的成功数与失败明细。
- **挪动焊点**（B/C）默认勾选。勾选时将目标点位移入新轨迹，取消勾选时保留目标原轨迹中的点位，并向新轨迹写入点位副本。
- **新轨迹后缀**（B/C）默认 `_Mapped`。例如参考轨迹 `OP10` 使用后缀 `_RH` 后，新轨迹名为 `OP10_RH`。输入留空时使用默认后缀。
- **操作数量严格(A)**：操作配对时要求两侧焊点数量严格相等。
- **仅更新位置(A)**：只更新焊点坐标，不改其它属性。

## 四、动作按钮

- **预览匹配**：执行匹配并把结果填入下方预览表，不写入场景。
- **执行写入**将预览结果写入 PS。A 更新焊点坐标，B/C 按预览名称生成新轨迹并分配点位。执行前需要预览和确认，可用 PS 撤销回退。
- **导出Excel**：把预览表内容导出到 Excel。
- **交换参考/目标**、**清空列表**：见上文。

预览表显示新轨迹、参考焊点、目标焊点、匹配依据和距离。参考点经过换系或镜像时，「依据」列显示变换提示。无法在同一坐标系计算距离时，距离显示为「—」。

---

## 五、匹配逻辑（多条轨迹时）

### A 模式：操作一对一配对
每条参考操作从目标操作里挑一个搭档（挑中的不再被别的参考操作选）。配对优先级：焊点数量 → 操作名相等 → 质心距离最近。配对后操作内部焊点取最近的未用焊点。参考轨迹之间互不干扰。

### B / C 模式：目标焊点共享全局池
所有目标操作的焊点共享一个候选池。使用距离时，按参考轨迹顺序为每个参考点取符合条件的最近未用目标点。仅名称匹配时使用两侧均唯一的同名点。每个目标焊点至多参与一次分配。

> 注意：B/C 是按参考集顺序的贪心匹配——若两条参考轨迹的焊点都靠近同一个待分配点，先处理的那条拿走。点分布密集或接近阈值边界时可能不是整体最优。

---

## 六、注意事项

- 两个网格**只接受焊接操作**，拾取到其它对象会被自动剔除并记日志。
- 镜像翻轴需按实际焊钳实测确定（None / X / Y / Z）。
- 执行写入可用 **PS 撤销**回退。
- 写入结束后可在日志中查看 `[Writer]` 统计与失败明细。

---

## 七、典型流程

**B 新焊点分配为例：**
1. 选「B 新焊点分配」。
2. 参考集网格拾取已分配的参考操作；目标集网格拾取待分配焊点清单操作。
3. 设置名称和距离条件。两侧坐标不同时勾选「不同车件参考系」，必要时在当前工程指定两侧局部坐标。
4. 按需调整姿态、轨迹参数和挪动选项，并填写新轨迹后缀。
5. 点「预览匹配」，核对新轨迹名、焊点配对与距离。
6. 确认无误点「执行写入」，检查生成的新轨迹；如需可「导出Excel」留档。

## 界面与构建

焊点分配窗口接入 `PickAwareTxForm`。参考集、目标集拾取中按 Esc 保留已选操作并退出。

本模块随 `TxTools.csproj` 构建。环境与注册方式见 [项目 README](../README.md)。

公共拾取实现位于 `SRC/PickFocus.cs` 和 `SRC/PickAwareTxForm.cs`；焦点回归位于独立测试目录。测试使用 SDK 控件替身和真实 WinForms 焦点/键盘消息，仍需在 PS 内确认实际拾取效果。

## 撤销与恢复（2026-10-07）

写坐标、迁移点位、复制参数、删除占位及镜像等属于同一场景撤销分组；部分失败需在当前 PS 工程按 Ctrl+Z 撤销，不把关闭事务称为自动回滚。

详见 [统一撤销与恢复说明](../docs/undo-safety.md)。
