# Agent 存储与维护

## 历史与记忆存储

`ConversationStore` 保存模型实际返回的消息和思考字段，存储序列化与网络序列化隔离。文件先写临时路径并 flush，再原子替换，保留一份备份；读取损坏文件时可以回退到备份。历史列表优先读取元数据。

完成、取消、失败及仅返回思考的响应分别保存。工具完成事件应在结果入库后触发。旧记录保持兼容；进程强制结束时尚未返回的流式内容无法恢复。

自动片段晋升默认关闭。重复执行次数不代表工程结果正确；待定经验需要独立验证。磁盘记录可能包含工程与个人数据，应在部署环境本地管理。

## 清理与恢复

`Optimize-DeployedMemory.ps1` 默认只预览，显式使用 `-Apply` 才修改目标目录。应用前应保存工程并关闭宿主，核对统计和文件清单。脚本先备份并校验 SHA-256，再归档文件；恢复时根据 manifest 核对原路径，避免覆盖新内容。

替换插件 DLL/PDB 前另行备份。WebView 界面为嵌入资源，修改源码后需要重新构建。文件恢复不等于 PS 场景或 CATIA 文档回滚。

`StorageRegression.cs` 检查字段隔离、配置兼容、历史往返、原子备份、恢复、上下文计数和工具结果配对；测试使用隔离目录，不调用在线模型。
