# 共享鲸鱼娘与前台配方

## 行为

- 同一 Windows 桌面会话只有一个桌宠窗口。所有 PS 插件进程共享显示状态，Agent GUI 和桌宠菜单均可隐藏它。
- 点击鲸鱼娘时选择前台的已注册 PS 进程。菜单获得焦点时保留点击前的 PS；其他应用在前台时不选择任意后台进程。
- 前台激活事件负责快速切换，750ms 定时检查负责宿主存活、共享状态和接管。只由当前宿主监听激活事件。
- 快捷面板由目标 PS 自己创建，命名管道仅传递打开入口请求。对象 ID、选择查询及配方代码不通过这个入口跨进程转发。
- 切换前台后旧面板收起并清除对象绑定。选择、类别查询、运行请求检查目标；C# 和 Python 真正修改场景前还会检查一次目标和研究。
- 宿主退出后其他进程自动接管；最后一个 PS 退出后桌宠退出，显示偏好继续保留。接管期间可能短暂消失。

## 实现

`Core/Multi/DesktopPetSession.cs` 使用会话命名互斥锁保护短事务，状态通过文件原子替换保存于 `%TEMP%/TxAgentDesktopPet/<会话号>/session.json`。宿主和助手用 PID 加启动时间判断存活，避免复用 PID。Electron 共享 profile 并使用单实例锁，阻止关闭与接管重叠时创建重复窗口。

后台启动仍沿用上游的延后初始化，不在命令静态构造阶段扫描场景或启动 Electron。工程与 WebView2 操作仍回到各自 PS 主线程。

## 验证

- `SharedPetRegression.cs`：实际 C# 协调器、控制器和命名管道在三个独立进程中运行；工程工具和桌宠助手以替身代替。13 项检查覆盖竞争启动、前台路由、快速激活、目标变化拒绝、全局开关、宿主异常退出接管和最后退出。
- `SharedPetElectronRegression.js`：实际 Electron 和动画素材，验证可见置顶动画、重复助手退出及关闭状态退出。
- `QuickRecipeControlsRegression.js`：生产快捷面板脚本验证前台变化清除绑定、禁用执行，且不发起新的场景查询。
- `recipe-controls-tests`：生产配方执行入口验证排队期间切换前台会阻止工程执行，返回前台后新请求可执行；同时保留原有控件和分享回归。
- `StartupResponsivenessRegression.js`：慢速助手启动期间保持 UI 消息循环响应，启动中隐藏、连续开启与故障回调共 8 项检查通过。

## 编译与更新

部署完整 `bin` 内容后关闭并重启所有 PS 进程；运行旧 DLL 的实例不能参与新版共享协调。

## 动作切换

播放器预加载常用动作，并在新动作就绪后原子切换。待机、思考、工作及挥手共四个常用动作在后台逐个解码并暂停备用；视频池最多六个元素，含两个播放槽位，使用后复用空闲槽补充缓存。未准备好的动作加载期间，当前动作继续播放，新动作的解码帧就绪后直接替换，无渐入渐出。

单纯更换两个视频元素的可见性仍会偶发合成空白，因此显示改为一个固定的透明 Canvas。视频始终不可见，只负责解码；每个视频帧使用 `globalCompositeOperation='copy'` 一次性替换整个画布，包括透明区域。无需先清空，也不与上个动作叠加。镜像和点击/落地挤压作用于画布；窗口移动、命中区域和配方入口保留原有行为。

`PetAnimationRegression.js` 使用实际 Electron 和 WebM，验证预解码缓存、四个普通动作、24 次不同间隔打断、单一画布、隐藏的视频层、无透明度动画、持续播放和资源上限，并对实际窗口抓帧检查角色未整体变淡或消失。还验证镜像和挤压作用于可见画布。测试不替代不同显卡、显示器缩放条件下的用户体验确认。

`PetAnimationLifecycleRegression.js` 运行生产播放器逻辑，验证就绪后硬切、单次复制画面、取消与过期回调、超时重试、缓存命中不重载、六元素上限和退出清理。更新内容位于 `Agent/UI/pet/dsh-pet/upstream/sprite.js` 和 `index.html`，部署时须同步桌宠目录。
