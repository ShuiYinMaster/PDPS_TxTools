- 跨实例执行遵守写入开关与线程标记；比较调用在两端强制检查只读属性，拒绝旧协议目标和嵌套转发。
- 重命名使用精确前后缀规则、唯一目标定位和批内冲突检查；代码恢复使用会话原始备份，保留文件编码并拒绝缺参编辑。
- Office 文件完成生成后再发布；模板按实际页序索引，校验页码和占位符，避免静默丢失图片或覆盖已有文件。
- 收紧相机、截图、上传文件和工作区路径的输入边界；本地记忆与 API 注解采用原子写入，并明确报告保存失败。
- 通过工程加载和模式切换事件识别文档生命周期，阻止旧事务或旧几何状态操作重载后的工程；部分失败保留变更标记。

- 旧版默认配方说明可使用 SHA-256 指纹精确匹配，保留对用户修改的检测。

### 行为变更

- 位置工具的旋转输入使用 RPY_ZYX 度；Euler 输出使用 Euler ZYZ 度。
- Python 探测、项目构建和跨实例执行按代码或写入操作声明；静态脚本检查不构成执行沙箱。
- 自动参考系 CATIA 导出一次处理一个操作；多操作导出需明确世界坐标系或逐项执行。参考系与引脚存在歧义时返回错误。

- CEE、仿真、CATIA、Excel 和真实工程操作仍需对应宿主、许可与环境验证。
