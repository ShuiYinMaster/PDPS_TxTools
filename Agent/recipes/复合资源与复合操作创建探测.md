专门测「复合资源」和「复合操作」这两类节点：创建入口在哪、创建时有没有类型可选、建出来的节点上还认不认这个类型。

SDK 层面两者差别很明确：

- `TxCompoundResourceCreationData` 有 `TypeName`（string，可读写），还有 `AbsoluteLocation`、`Collection`、`Name` —— **创建时可以指定类型**。
- `TxCompoundPartCreationData` 同样有 `TypeName`。
- `TxCompoundOperationCreationData` 只有 `Name`、`Duration`、`Description` —— **没有任何类型字段**，复合操作的"种类"不由创建时决定，由里面放什么子操作决定。

配方会实测这一点：留空类型名建一次、指定类型名建一次、再拿候选类型名逐个试，看谁被接受、被拒时报什么。建完立刻读 `eMSType` 和节点上的类型相关属性，确认类型是否落地。

Func<Exception, string> msgOf = delegate(Exception e)
{
    if (e == null) return "";
    Exception inner = e.InnerException == null ? e : e.InnerException;
    string m = inner.Message == null ? "" : inner.Message;
    m = m.Replace("\r", " ").Replace("\n", " ").Replace("|", "/").Trim();
    if (m.Length > 140) m = m.Substring(0, 140) + "…";
    return inner.GetType().Name + ": " + m;
};

Func<string, Type> findType = delegate(string fullName)
{
    Type t = null;
    try { t = Type.GetType(fullName + ", Tecnomatix.Engineering", false); } catch (Exception) { }
    if (t == null) { try { t = typeof(ITxObject).Assembly.GetType(fullName, false); } catch (Exception) { } }
    return t;
};

Func<ITxObject, string> nameOf = delegate(ITxObject o)
{
    if (o == null) return "(空)";
    string n = "";
    try { n = o.Name; } catch (Exception) { }
    if (string.IsNullOrEmpty(n)) return "(未命名)";
    n = n.Replace("|", "/");
    if (n.Length > 36) n = n.Substring(0, 36) + "…";
    return n;
};

// 读节点上所有"看起来像类型"的属性，供判断类型有没有落地
Func<object, string> typePropsOf = delegate(object o)
{
    if (o == null) return "—";
    var parts = new List<string>();
    System.Reflection.PropertyInfo[] ps;
    try
    {
        ps = o.GetType().GetProperties(System.Reflection.BindingFlags.Public
                                     | System.Reflection.BindingFlags.Instance);
    }
    catch (Exception) { return "—"; }

    foreach (System.Reflection.PropertyInfo pi in ps)
    {
        if (!pi.CanRead) continue;
        string pn = pi.Name;
        bool looksType = pn.IndexOf("Type", StringComparison.OrdinalIgnoreCase) >= 0
                      || pn.IndexOf("Class", StringComparison.OrdinalIgnoreCase) >= 0
                      || pn.IndexOf("Kind", StringComparison.OrdinalIgnoreCase) >= 0
                      || pn.IndexOf("Category", StringComparison.OrdinalIgnoreCase) >= 0;
        if (!looksType) continue;
        if (string.Equals(pn, "GetType", StringComparison.Ordinal)) continue;
        string val = "?";
        try
        {
            object v = pi.GetValue(o, null);
            val = v == null ? "(null)" : Convert.ToString(v);
        }
        catch (Exception) { continue; }
        if (val == null) val = "";
        if (val.Length > 30) val = val.Substring(0, 30) + "…";
        parts.Add(pn + "=" + val);
    }
    return parts.Count == 0 ? "无类型相关属性" : string.Join("；", parts.ToArray());
};

    Func<string, bool> addCand = delegate(string s)
    {
        if (string.IsNullOrEmpty(s)) return false;
        s = s.Trim();
        if (s.Length == 0) return false;
        foreach (string x in candidates)
            if (string.Equals(x, s, StringComparison.OrdinalIgnoreCase)) return false;
        candidates.Add(s);
        return true;
    };

    Type eMSTypeEnum = findType("Tecnomatix.Engineering.eMSObjectType");
    if (eMSTypeEnum != null && eMSTypeEnum.IsEnum)
    {
        try { foreach (string n in Enum.GetNames(eMSTypeEnum)) addCand(n); }
        catch (Exception) { }
    }

    // 场景里已有复合资源的类型属性值

    {
        System.Reflection.PropertyInfo[] ps = null;
        try
        {
            ps = o.GetType().GetProperties(System.Reflection.BindingFlags.Public

        if (ps == null) continue;
