# 默认小配方

下面 5 个配方随 `TxTools.dll` 内嵌提供。首次读取配方时写入现有 `memory/recipes` 目录，刷新鲸鱼娘的快捷配方面板即可查看。

| 配方 | 使用方式 |
| --- | --- |
| [一键修改对象颜色](defaults/default_set_color.md) | 绑定对象，填写 `#RRGGBB`；可包含下属对象。 |
| [从标记几何中心生成焊点](defaults/default_geometry_weld_points.md) | 支持实体、曲面、通用几何及 Block；组件自动遍历子级，执行后直接创建，默认仅跳过同位置的点。 |
| [对象批量编号](defaults/default_number_objects.md) | 按绑定顺序改为前缀 + 序号，可设置起始序号和位数。 |
| [一键显示或隐藏对象](defaults/default_visibility.md) | 勾选表示显示，取消表示隐藏；可包含下属对象。 |
| [查看对象世界坐标](defaults/default_object_coordinates.md) | 表格显示对象原点或几何中心的 X/Y/Z，单位 mm。 |

## 使用与修改

- 配方卡片提供删除按钮；同名文件导入时可选择增加副本或更新已有配方。更新保留已有配方的运行记录。

- 不经过模型，运行时沿用参数校验、研究校验、共享执行锁、Undo 和执行日志。
- 普通参数会记忆，对象 ID 不持久保存，换研究后重新取对象。
- 同 ID 的已有配方保持原样；已安装的默认配方被修改或删除后，重启不会覆盖或重新添加。标记记录在 `.default-recipes-installed`。
- 焊点配方旧版若名称、说明、参数和代码均未修改，首次读取时自动升级到当前版；保留运行记录，原文件备份为 `.md.before-keyword-*`。用户修改过的版本与删除状态均保留。
- 想恢复某个已删除的默认配方，可在“配方管理”中导入对应 Markdown 文件，得到新副本。
- 几何提取使用 `ITxGeometry` 覆盖实体、曲面和通用几何，使用 `ITxGroup` 识别 Block。匹配的几何或 Block 作为单个标记，组件始终展开查找子级。空组、坐标系和注释跳过，父子重叠绑定去重。执行后直接创建焊点。
- 创建前统一校验候选中心与姿态，直接通过 `OperationRoot.CreateWeldLocationOperation` 创建；制造焊点用中心平移向量、位置操作用完整 `GeometricCenter`。圆柱取中心，不取端面；法向、零件绑定及焊枪工艺参数由使用者设置。
- 筛选按名称包含输入的关键字，不区分大小写，留空匹配全部；不固定排除 CO2，也不要求 DPUB 格式。名称符合 DPUB 时仍整理为工位／零件号／编号，例如 `DPUB-501021339-XWS_00.001_T1EJ-0000116179-RSW` → `T1EJ_501021339_116179`；其他格式沿用几何体原名，无名称时使用 `WP_001` 等编号。名称仅用于关键字匹配及命名，不用于去重。同名且位置不同的焊点分别创建；位置去重容差默认 0，可按需调整。
- [批量调整机器人与资源姿态](批量调整机器人与资源姿态.md) 可手动导入。默认仅处理绑定范围，执行后直接调整；选中设备内部几何或链接时定位最近所属设备。全研究扫描须显式选择，静态资源和缺少命名姿态的设备跳过。所有候选读取完成后才调整，单设备写入失败尝试恢复，恢复失败停止后续执行。

## 验证范围

测试位于同级 `TxTools.Local/tests/Agent/maintenance`，输出位于 `TxTools.Local/build/tests`。

- `RecipeGeometryPoseSdk.ps1` 使用真实 Markdown 解析、参数生成器和 PS 2402 SDK / C# 5 编译两份配方的全部下拉组合，并验证旧默认配方升级、备份、自定义保护、删除及运行记录保留。
- `Run-RecipeGeometryPose.ps1` 将实际配方代码运行在内存场景中，验证实体／曲面／Block 识别、组件遍历、父子选择去重、位置去重、同名异位创建、直接执行、中心预校验、创建失败清理，以及设备类别、内部对象所属设备、明确全研究范围、缺少姿态、失败恢复与恢复失败停止。

内存场景测试不替代 Process Simulate 中的实际工程验证。
