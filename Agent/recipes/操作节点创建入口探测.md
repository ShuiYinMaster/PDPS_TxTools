探测当前研究里「操作节点」能建哪些类型、入口在哪、需要什么创建数据（CreationData），并可以按入口逐项做创建测试。

只读探测阶段不改变场景。创建测试阶段会真实建节点，默认创建后立即删除；把「创建后保留」勾上才留下，方便观察。

回答三个问题：

1. **有哪些操作类型可以创建** —— 用 `CanCreateChildOperationOfType(Type)` 逐类型判定，这是 SDK 自己的口径，比猜方法名可靠。
2. **创建入口在哪** —— 反射 `OperationRoot`（以及已有操作容器）上的 `Create*Operation` 方法，列出方法签名和数据类。根和复合操作能建的东西不一样，这点只有实测才知道。
3. **建得出来吗** —— 对挑中的方法用默认数据真的调一次，成功就给出新节点名，失败就给出 SDK 抛的原始错误。

## 参数

```json
[
  {"Name":"scope","Label":"探测范围","Kind":"text","Required":false,"Default":"root","Help":"根节点能建的入口最少；复合操作能建的位置操作、焊接操作通常只在容器上暴露。","Choices":[{"label":"仅操作根节点","value":"root"},{"label":"根 + 现有操作容器（最多 8 个）","value":"all"},{"label":"仅当前选中的操作","value":"selection"}]},

  {"Name":"name_prefix","Label":"测试节点名前缀","Kind":"text","Required":false,"Default":"OPPROBE_","Help":"创建测试用的节点名。清理按钮只删带这个前缀的节点。"},
  {"Name":"keep","Label":"创建后保留","Kind":"bool","Required":false,"Default":"false","Help":"不勾选时创建成功立即删除，只留结果记录。"}
]
```

```csharp
// 操作节点创建入口探测 —— 自包含实现，不依赖插件中的新增模块。
// 只读探测不写场景；创建测试默认建完即删。
var sb = new StringBuilder();

// ── 参数归一化 ──
string scopeArg = scope == null ? "" : Convert.ToString(scope).Trim().ToLowerInvariant();
if (scopeArg.Length == 0) scopeArg = "root";
string methodArg = op_method == null ? "" : Convert.ToString(op_method).Trim();
string prefix = name_prefix == null ? "" : Convert.ToString(name_prefix).Trim();
if (prefix.Length == 0) prefix = "OPPROBE_";
bool keepCreated = Convert.ToBoolean(keep);
bool cleanupOnly = methodArg.Equals("cleanup", StringComparison.OrdinalIgnoreCase)
                || methodArg.Equals("#cleanup", StringComparison.OrdinalIgnoreCase);
bool createAll = methodArg == "*";
string singleMethod = (!cleanupOnly && !createAll && methodArg.Length > 0) ? methodArg : "";

string scopeText = scopeArg == "all" ? "根 + 现有操作容器"
                 : (scopeArg == "selection" ? "当前选中的操作" : "仅操作根");
string modeText = cleanupOnly ? "只清理"
                : (createAll ? "全部逐个创建测试"
                : (singleMethod.Length > 0 ? "单点创建测试：" + singleMethod : "只探测，不创建"));

sb.AppendLine("## 操作节点创建入口探测");
sb.AppendLine();
sb.AppendLine("| 项目 | 值 |");
sb.AppendLine("| --- | --- |");
sb.AppendLine("| 探测范围 | " + scopeText + " |");
sb.AppendLine("| 创建模式 | " + modeText + " |");
sb.AppendLine("| 测试名前缀 | `" + prefix + "` |");
sb.AppendLine("| 创建后保留 | " + (keepCreated ? "是" : "否（建完即删）") + " |");
sb.AppendLine();

var doc = TxApplication.ActiveDocument;
if (doc == null)
{
    sb.AppendLine("**没有活动研究**。先打开一个 Process Simulate 研究再运行。");
    return sb.ToString();
}

object rootObj = null;
try { rootObj = doc.OperationRoot; }
catch (Exception ex) { sb.AppendLine("读取 OperationRoot 失败：" + ex.Message); return sb.ToString(); }
if (rootObj == null)
{
    sb.AppendLine("**OperationRoot 为空**。当前研究没有操作树，先确认研究已正确加载。");
    return sb.ToString();
}

// ── 通用小工具 ──
Func<Exception, string> msgOf = delegate(Exception e)
{
    if (e == null) return "";
    Exception inner = e.InnerException == null ? e : e.InnerException;
    string m = inner.Message == null ? "" : inner.Message;
    m = m.Replace("\r", " ").Replace("\n", " ").Replace("|", "/").Trim();
    if (m.Length > 150) m = m.Substring(0, 150) + "…";
    return inner.GetType().Name + ": " + m;
};

Func<ITxObject, string> nameOf = delegate(ITxObject o)
{
    if (o == null) return "(空)";
    string n = "";
    try { n = o.Name; } catch (Exception) { }
    if (string.IsNullOrEmpty(n)) return "(未命名)";
    n = n.Replace("|", "/");
    if (n.Length > 40) n = n.Substring(0, 40) + "…";
    return n;
};

// 一个类型上可作为"创建入口"的方法：名字 Create*，单参数，参数类型是 *CreationData。
Func<Type, System.Reflection.MethodInfo[]> createMethodsOf = delegate(Type t)
{
    var list = new List<System.Reflection.MethodInfo>();
    if (t == null) return list.ToArray();
    System.Reflection.MethodInfo[] ms;
    try
    {
        ms = t.GetMethods(System.Reflection.BindingFlags.Public | System.Reflection.BindingFlags.Instance);
    }
    catch (Exception) { return list.ToArray(); }

    foreach (System.Reflection.MethodInfo mi in ms)
    {
        if (mi == null || mi.IsSpecialName) continue;
        if (!mi.Name.StartsWith("Create", StringComparison.Ordinal)) continue;
        System.Reflection.ParameterInfo[] ps;
        try { ps = mi.GetParameters(); } catch (Exception) { continue; }
        if (ps.Length != 1) continue;
        string ptn = "";
        try { ptn = ps[0].ParameterType.Name; } catch (Exception) { }
        if (ptn.IndexOf("CreationData", StringComparison.OrdinalIgnoreCase) < 0) continue;
        list.Add(mi);
    }
    list.Sort(delegate(System.Reflection.MethodInfo a, System.Reflection.MethodInfo b)
    {
        return string.Compare(a.Name, b.Name, StringComparison.Ordinal);
    });
    return list.ToArray();
};

// ── 操作树快照 ──
ITxObjectCollection rootColl = rootObj as ITxObjectCollection;
var descendants = new List<ITxObject>();
if (rootColl != null)
{
    try
    {
        var all = rootColl.GetAllDescendants(new TxTypeFilter(typeof(ITxObject)));
        if (all != null) foreach (ITxObject o in all) if (o != null) descendants.Add(o);
    }
    catch (Exception ex) { sb.AppendLine("遍历操作树失败：" + msgOf(ex)); sb.AppendLine(); }
}

// ── 已有操作节点 ──
int opCount = 0;
var typeCount = new Dictionary<string, int>(StringComparer.Ordinal);
foreach (ITxObject o in descendants)
{
    if (!(o is ITxOperation)) continue;
    opCount++;
    string tn = o.GetType().Name;
    int c;
    if (typeCount.TryGetValue(tn, out c)) typeCount[tn] = c + 1; else typeCount[tn] = 1;
}

sb.AppendLine("### 场景中已有的操作节点");
sb.AppendLine();
if (opCount == 0)
{
    sb.AppendLine("操作树里还没有任何操作节点。所有创建入口都还没被验证过，下面的判定就是起点。");
}
else
{
    sb.AppendLine("共 " + opCount + " 个，按运行时类型统计：");
    sb.AppendLine();
    sb.AppendLine("| 类型 | 数量 |");
    sb.AppendLine("| --- | --- |");
    var typeKeys = new List<string>(typeCount.Keys);
    typeKeys.Sort(StringComparer.Ordinal);
    foreach (string k in typeKeys) sb.AppendLine("| `" + k + "` | " + typeCount[k] + " |");
}
sb.AppendLine();

// ── 清理模式：先做完就返回，不再探测 ──
if (cleanupOnly)
{
    sb.AppendLine("### 清理结果");
    sb.AppendLine();
    var hits = new List<ITxObject>();
    foreach (ITxObject o in descendants)
    {
        string nm = "";
        try { nm = o.Name; } catch (Exception) { }
        if (!string.IsNullOrEmpty(nm) && nm.StartsWith(prefix, StringComparison.OrdinalIgnoreCase)) hits.Add(o);
    }
    if (hits.Count == 0)
    {
        sb.AppendLine("没有找到名字以 `" + prefix + "` 开头的节点，无需清理。");
    }
    else
    {
        int deleted = 0;
        var fails = new List<string>();
        foreach (ITxObject o in hits)
        {
            string nm = nameOf(o);
            try { o.Delete(); deleted++; }
            catch (Exception ex) { fails.Add(nm + " → " + msgOf(ex)); }
        }
        sb.AppendLine("命中 " + hits.Count + " 个，删除成功 " + deleted + " 个。");
        if (fails.Count > 0)
        {
            sb.AppendLine();
            sb.AppendLine("删除失败的：");
            foreach (string f in fails) sb.AppendLine("- " + f);
        }
    }
    sb.AppendLine();
    sb.AppendLine("---");
    sb.AppendLine();
    sb.AppendLine("焊接位置操作在 MfgRoot 下会连带生成焊点（TxWeldPoint），焊点名不带测试前缀，");
    sb.AppendLine("若创建过 `CreateWeldLocationOperation`，请到 MfgRoot 手工确认有没有残留焊点。");
    return sb.ToString();
}

// ── 作用域 ──
var scopeObjs = new List<object>();
var scopeLabels = new List<string>();

if (scopeArg == "selection")
{
    try
    {
        TxObjectList sel = TxApplication.ActiveSelection.GetItems();
        if (sel != null)
        {
            foreach (ITxObject o in sel)
            {
                if (o == null) continue;
                if (!(o is ITxOperation) && !(o is ITxObjectCollection)) continue;
                scopeObjs.Add(o);
                scopeLabels.Add("选中：" + nameOf(o) + "（" + o.GetType().Name + "）");
            }
        }
    }
    catch (Exception ex) { sb.AppendLine("读取当前选择失败：" + msgOf(ex)); sb.AppendLine(); }

    if (scopeObjs.Count == 0)
    {
        sb.AppendLine("**没有选中可操作的对象**。先选一个操作节点（或把探测范围改成「仅操作根节点」）。");
        return sb.ToString();
    }
}
else
{
    scopeObjs.Add(rootObj);
    scopeLabels.Add("操作根（OperationRoot）");

    if (scopeArg == "all")
    {
        int picked = 0;
        foreach (ITxObject o in descendants)
        {
            if (picked >= 8) break;
            if (!(o is ITxOperation)) continue;
            if (createMethodsOf(o.GetType()).Length == 0) continue;
            scopeObjs.Add(o);
            scopeLabels.Add("操作：" + nameOf(o) + "（" + o.GetType().Name + "）");
            picked++;
        }
        if (picked == 0)
        {
            sb.AppendLine("操作树里没有带 `Create*Operation` 入口的容器，只能探测根节点。");
            sb.AppendLine();
        }
    }
}

// ── 一、按类型判定能否建 ──
sb.AppendLine("### 一、按类型判定：能否作为子操作创建");
sb.AppendLine();
sb.AppendLine("判定方式是 SDK 的 `CanCreateChildOperationOfType(Type)`，对操作根调用。true 表示当前研究接受这个类型。");
sb.AppendLine();

System.Reflection.MethodInfo canTypeMi = null;
try
{
    canTypeMi = rootObj.GetType().GetMethod("CanCreateChildOperationOfType",
        new Type[] { typeof(Type) });
}
catch (Exception) { }

if (canTypeMi == null)
{
    sb.AppendLine("当前 SDK 版本没有暴露 `CanCreateChildOperationOfType`，跳过本节，只能看下面的方法级结果。");
    sb.AppendLine();
}
else
{
    Type[] asmTypes = null;
    try { asmTypes = typeof(ITxOperation).Assembly.GetTypes(); }
    catch (System.Reflection.ReflectionTypeLoadException ex) { asmTypes = ex.Types; }
    catch (Exception ex) { sb.AppendLine("枚举程序集类型失败：" + msgOf(ex)); }

    var okTypes = new List<string>();
    var maybeTypes = new List<string>();
    int denied = 0, checkedTypes = 0;

    if (asmTypes != null)
    {
        foreach (Type x in asmTypes)
        {
            if (x == null || x.IsInterface || x.IsAbstract) continue;
            if (!x.IsVisible) continue;
            if (!typeof(ITxOperation).IsAssignableFrom(x)) continue;
            if (x == rootObj.GetType()) continue;
            checkedTypes++;
            bool ok = false;
            try { ok = Convert.ToBoolean(canTypeMi.Invoke(rootObj, new object[] { x })); }
            catch (Exception) { continue; }

            if (ok)
            {
                okTypes.Add(x.Name);
            }
            else
            {
                denied++;
                // 位置操作、焊接这类通常要挂在容器或设备下，单独标出来便于判断
                string n = x.Name;
                if (n.IndexOf("Location", StringComparison.OrdinalIgnoreCase) >= 0
                    || n.IndexOf("Weld", StringComparison.OrdinalIgnoreCase) >= 0
                    || n.IndexOf("Robotic", StringComparison.OrdinalIgnoreCase) >= 0)
                    maybeTypes.Add(n);
            }
        }
    }

    sb.AppendLine("检查 " + checkedTypes + " 个操作类型：可创建 **" + okTypes.Count + "** 个，拒绝 " + denied + " 个。");
    sb.AppendLine();

    if (okTypes.Count > 0)
    {
        okTypes.Sort(StringComparer.Ordinal);
        sb.AppendLine("可创建的类型：");
        sb.AppendLine();
        foreach (string t in okTypes) sb.AppendLine("- `" + t + "`");
    }
    else
    {
        sb.AppendLine("根节点下没有任何类型返回 true。常见原因：研究处于只读/未打开建模状态，");
        sb.AppendLine("或者这个研究要先有复合操作，位置操作只能在容器下创建。");
    }

    if (maybeTypes.Count > 0)
    {
        maybeTypes.Sort(StringComparer.Ordinal);
        sb.AppendLine();
        sb.AppendLine("被拒绝但属于位置/焊接/机器人类的类型（多半要在复合操作或设备下建）：");
        sb.AppendLine();
        foreach (string t in maybeTypes) sb.AppendLine("- `" + t + "`");
    }
    sb.AppendLine();
}

// ── 二、方法级入口 ──
sb.AppendLine("### 二、创建入口（Create*Operation 方法）");
sb.AppendLine();
sb.AppendLine("| # | 作用域 | 方法 | 数据类 | CanCreate（默认数据） | 创建测试 |");
sb.AppendLine("| --- | --- | --- | --- | --- | --- |");

int seq = 0;
int createdCount = 0;
int attemptCount = 0;
var entrySamples = new List<string>();
var leftovers = new List<ITxObject>();

// 引用池：设备类操作的 CreationData 必须带设备/机器人/焊枪，否则一定建不出来。
// 这里只做"同类型第一个"的兜底填充，够用来验证入口通不通，不负责选对设备。
// 只有真要做创建测试时才遍历物理根，纯探测不付这个成本。
var refPool = new List<ITxObject>();
if (createAll || singleMethod.Length > 0)
{
    try
    {
        var physical = doc.PhysicalRoot as ITxObjectCollection;
        if (physical != null)
        {
            var objs = physical.GetAllDescendants(new TxTypeFilter(typeof(ITxObject)));
            if (objs != null) foreach (ITxObject o in objs) if (o != null) refPool.Add(o);
        }
    }
    catch (Exception) { }
}
var refNames = new string[] { "Device", "Robot", "Tool", "Gun", "Gripper", "Human",
                              "SimulatedObject", "GraspedObject", "LeadingPart" };
int refFilled = 0;

for (int si = 0; si < scopeObjs.Count; si++)
{
    object scopeObj = scopeObjs[si];
    string scopeLabel = scopeLabels[si];
    System.Reflection.MethodInfo[] methods = createMethodsOf(scopeObj.GetType());

    System.Reflection.MethodInfo[] cached = null;
    try
    {
        cached = scopeObj.GetType().GetMethods(
            System.Reflection.BindingFlags.Public | System.Reflection.BindingFlags.Instance);
    }
    catch (Exception) { cached = new System.Reflection.MethodInfo[0]; }

    foreach (System.Reflection.MethodInfo mi in methods)
    {
        seq++;
        string mname = mi.Name;
        Type pt = null;
        string dtName = "?";
        try
        {
            pt = mi.GetParameters()[0].ParameterType;
            dtName = pt.Name;
        }
        catch (Exception) { }

        string shortName = mname.StartsWith("Create", StringComparison.Ordinal) ? mname.Substring(6) : mname;
        string testName = prefix + shortName + "_" + seq.ToString();

        // 造数据：优先 ctor(string name)，其次无参 + 写 Name
        object data = null;
        string ctorForm = "";
        if (pt != null)
        {
            try
            {
                System.Reflection.ConstructorInfo c1 = null;
                try { c1 = pt.GetConstructor(new Type[] { typeof(string) }); }
                catch (Exception) { }
                if (c1 != null)
                {
                    data = c1.Invoke(new object[] { testName });
                    ctorForm = "new " + dtName + "(\"" + testName + "\")";
                }
                else
                {
                    System.Reflection.ConstructorInfo c0 = null;
                    try { c0 = pt.GetConstructor(Type.EmptyTypes); }
                    catch (Exception) { }
                    if (c0 != null)
                    {
                        data = c0.Invoke(null);
                        ctorForm = "new " + dtName + "()";
                        try
                        {
                            System.Reflection.PropertyInfo np = pt.GetProperty("Name", typeof(string));
                            if (np != null && np.CanWrite && np.GetIndexParameters().Length == 0)
                                np.SetValue(data, testName, null);
                        }
                        catch (Exception) { }
                    }
                }
            }
            catch (Exception ex) { ctorForm = "构造失败：" + msgOf(ex); }
        }
        if (ctorForm.Length == 0) ctorForm = "无可用构造函数";

        // 引用字段兜底填充：属性名命中且为空时，塞场景里第一个同类型对象
        if (data != null && pt != null && refPool.Count > 0)
        {
            System.Reflection.PropertyInfo[] props = null;
            try
            {
                props = pt.GetProperties(System.Reflection.BindingFlags.Public
                                       | System.Reflection.BindingFlags.Instance);
            }
            catch (Exception) { }

            if (props != null)
            {
                foreach (System.Reflection.PropertyInfo pi in props)
                {
                    if (!pi.CanWrite) continue;
                    try { if (pi.GetIndexParameters().Length != 0) continue; }
                    catch (Exception) { continue; }

                    bool wanted = false;
                    foreach (string rn in refNames)
                        if (string.Equals(pi.Name, rn, StringComparison.Ordinal)) { wanted = true; break; }
                    if (!wanted) continue;

                    try
                    {
                        if (pi.GetValue(data, null) != null) continue;
                        foreach (ITxObject cand in refPool)
                        {
                            if (!pi.PropertyType.IsAssignableFrom(cand.GetType())) continue;
                            pi.SetValue(data, cand, null);
                            refFilled++;
                            break;
                        }
                    }
                    catch (Exception) { }
                }
            }
        }

        // 配对 CanCreate*：优先取参数类型与数据类一致的重载
        string canText = "—";
        if (data != null)
        {
            System.Reflection.MethodInfo canMi = null;
            foreach (System.Reflection.MethodInfo cm in cached)
            {
                if (!string.Equals(cm.Name, "Can" + mname, StringComparison.Ordinal)) continue;
                System.Reflection.ParameterInfo[] cps;
                try { cps = cm.GetParameters(); } catch (Exception) { continue; }
                if (cps.Length != 1) continue;
                if (canMi == null) canMi = cm;
                if (pt != null && cps[0].ParameterType == pt) { canMi = cm; break; }
            }

            if (canMi != null)
            {
                try
                {
                    object r = canMi.Invoke(scopeObj, new object[] { data });
                    canText = Convert.ToBoolean(r) ? "是" : "否";
                }
                catch (Exception ex) { canText = "异常（" + msgOf(ex) + "）"; }
            }
        }

        // 创建测试
        string testText = "—";
        bool wantCreate = createAll
            || (singleMethod.Length > 0
                && (string.Equals(mname, singleMethod, StringComparison.OrdinalIgnoreCase)
                    || mname.IndexOf(singleMethod, StringComparison.OrdinalIgnoreCase) >= 0));

        if (wantCreate)
        {
            if (data == null)
            {
                testText = "跳过（数据类造不出来）";
            }
            else
            {
                attemptCount++;
                try
                {
                    object created = mi.Invoke(scopeObj, new object[] { data });
                    ITxObject createdObj = created as ITxObject;
                    if (createdObj == null)
                    {
                        testText = "已调用，返回 " + (created == null ? "null" : created.GetType().Name);
                    }
                    else
                    {
                        createdCount++;
                        string cnm = "";
                        try { cnm = createdObj.Name; } catch (Exception) { }
                        testText = "成功 → `" + (cnm == null ? "" : cnm.Replace("|", "/")) + "`（" + createdObj.GetType().Name + "）";
                        if (!keepCreated)
                        {
                            try { createdObj.Delete(); testText += "，已删除"; }
                            catch (Exception dx)
                            {
                                testText += "，**删除失败**：" + msgOf(dx);
                                leftovers.Add(createdObj);
                            }
                        }
                        else
                        {
                            leftovers.Add(createdObj);
                        }
                    }
                }
                catch (Exception ex)
                {
                    testText = "**失败**：" + msgOf(ex);
                }
            }
        }

        sb.AppendLine("| " + seq + " | " + scopeLabel + " | `" + mname + "` | `" + dtName + "` | " + canText + " | " + testText + " |");

        if (data != null && ctorForm.StartsWith("new ", StringComparison.Ordinal))
            entrySamples.Add(scopeLabel + " → scope." + mname + "(" + ctorForm + ")");
    }
}

sb.AppendLine();
sb.AppendLine("共找到 " + seq + " 个创建入口。");
if (refFilled > 0)
```
