# DeviceZAligner — 设备 Z 向对齐

源码核对日期：2026-10-07。

## 当前状态

原有 README 将此独立插件标记为“目前无法正常运行”。本次同步未修改该模块业务源码，也未完成 PS 实机修复验证，因此保留此状态，不将编译成功视为功能已修复。

## 命令与预期功能

- 命令：`DeviceZAligner`；入口类：`DeviceZAlignerCmd`。
- 扫描活动场景的设备，显示当前 Z、检测到的最低点、偏移量及跳过原因。
- 按设备类型和名称排除焊枪等对象，尝试将设备最低点对齐到世界 Z=0。
- 源码提供检测回退、日志和撤销路径；使用时应先在场景副本中核对最低点检测与偏移结果。

## 文件与相关模块

`DeviceZAligner.cs` 包含命令、窗体、设备信息和对齐逻辑。TxAgent 的 `align_devices_z` 使用独立的 `Agent/Ps/DeviceZAlignService.cs`；不能用该工具的行为推断本窗口已经修复。
