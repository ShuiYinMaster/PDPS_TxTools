# CatiaPartTree — 零件树整理

从 CATIA 产品树或 PS 所选零件分支生成目标结构预览，并创建、复用 CompoundPart 容器及归类现有零件。命令入口类仍为 `CatiaPartTreeCmd`，显示名称为 `.零件树整理`。

## 使用

PS 对象统一使用 SDK 原生拾取器：点击拾取行后到 PS 树或场景选对象，Esc 结束拾取，使用网格自带删除功能移除输入。三个拾取框使用明确标题和边框，高度按五行数据、表头和拾取行设置，宽度由父布局统一三等分，总体窗口宽度固定为 650 个逻辑像素，三个拾取框按三等分填充，长对象名称不改变列宽；高 DPI 随窗体缩放。CATIA 外部产品树仍由 CATIA 接口读取，PS 拾取器不支持读取 CATIA 文档。

1. 在第一个拾取框选择一个 PS 零件分支；使用 CATIA 时，打开产品后点击“读取 CATIA 活动产品”。
2. 在第二个拾取框选择目标零件容器。
3. 选择“仅创建容器结构”或“创建结构并归类已有零件”，设置是否保留来源根。
4. 在左树勾选参与分支。选中装配节点，可取消“创建此层容器”，将子节点提升到上级。左右树等宽等高。
5. 拖动来源或预览节点到装配节点文字处，将其移入该容器；放到同级节点上沿，排在该节点前。不能移动根或拖入自身后代。拖动只修改草稿，实际创建和移动仍须检查后执行。
6. 输入就绪或编辑后自动更新预览；“重新扫描场景”用于采集 PS 外部变更。双击右树容器或按 F2 编辑目标名称，不修改原始名称和已有 PS 对象名称。
7. 点击问题定位来源。CATIA 叶子存在匹配歧义时，先选中左树叶子，再在第三个原生拾取框选取正确的 PS 零件；删除该框中的对象可恢复自动匹配。自动刷新后确认问题消除。
8. 点击底部执行按钮，检查完成数量。“继续快速分序”在完整执行后使用 PS 整理结果，否则使用当前结构草稿。

## 匹配与执行

PS 来源按实际对象身份归类；CATIA 来源按原始名称或 PartNumber 精确匹配 PS 零件。无匹配、多候选或同一实例被多个来源节点匹配时禁止应用，不使用名称包含匹配自动决定归属。

目标同级仅存在一个同名 CompoundPart 时复用；多个同名对象或类型不符时报告问题。跳层保留子节点，叶子零件不创建空容器。未勾选归类选项时仅生成结构。

执行前核对活动文档和对象快照，执行后验证移动父级。场景变更纳入一个撤销分组，部分失败会尝试恢复失败项的父级和位置；补偿不完整及已成功项目需在当前工程 Ctrl+Z 撤销。普通流程不保存或重载工程。

## 限制

目标结构通过是否创建当前层、名称和新建容器创建顺序调整。同级存在复用容器时，已有对象顺序由 PS 原生树管理。搜索仅过滤显示；部分纳入的分支有文字标记，刷新保留展开和选择状态。编辑后自动重新计算预览，计算期间不能执行；右树显示目标名称，不追加状态文本。

不支持拖动重设父级、规则预设或跨会话映射恢复。PS 来源移动后应重新读取来源。实际对象创建、拾取和撤销需在 PS 2402 宿主验收。预览计算失败会清空旧结果并禁用执行；无实际变更时显示“无需变更”。错误的来源输入不会复用上一来源，失效实例绑定可重新拾取。执行前失败不提示撤销；写入中断保留已完成数量、失败位置和补偿信息。

通过 `tools/Build.ps1` 随主工程构建。公共规划模型与写入校验位于 `SRC/TreeWorkflow.cs`；CATIA 读取继续复用现有服务。
