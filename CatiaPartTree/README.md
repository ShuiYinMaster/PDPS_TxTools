# CatiaPartTree — 零件树整理

从当前 CATIA 文档、CATProduct、3DXML 或 STEP 文件读取零件和装配，编辑目标零件树，转换 JT 并封装为 COJT，在当前 PS 离线工程创建 CompoundPart 容器并导入实例。也支持整理 PS 已有零件。命令入口为 `CatiaPartTreeCmd`。

## CATIA 转换与导入

1. 在 CATIA 打开 CATProduct 或 CATPart。CATProduct 可以没有 CATPart 引用，此时仍可读取结构并创建复合零件。装配引用必须完整加载；转换读取磁盘上已有的 CATPart 几何，不受 CATIA 文档未保存状态阻断。未保存的零件几何修改不包含在转换结果中；CATProduct 的结构和位置按当前会话读取。
2. 在 PS 打开目标离线工程，启动“零件树整理”，来源选择“CATIA 当前文档”，点击“读取 / 重新读取”。来源路径显示在顶部。也可选择“CATProduct 文件”直接指定装配文件作为坐标基准，详见下文。
3. 在原生单对象选取框中确认当前 PS 工程的目标父容器，默认物理根。勾选“新建目标根容器”并填写名称；取消勾选则直接使用选取的目标。CATIA 的导入实例自动对应来源节点，无需手动绑定现有实例。
4. 确认“COJT 保存至”。输入框显示库内的基准保存文件夹，默认模糊匹配当前系统库内名称含 `product` 的文件夹（优先精确 `product`，如 `1_Products`），不再把 CATIA 文档名追加在路径中。勾选“以 CATIA 文档名建子文件夹”（默认勾选）时，实际模型目录为该基准文件夹下的 CATIA 文档名；取消勾选则直接使用基准文件夹。可选“按层级建文件夹”（默认不勾选），勾选后按目标复合零件层级建立子文件夹。支持输入库内相对路径、完整路径或点击“浏览…”指定基准文件夹。该位置保存模型文件，上方原生选取框指定 PS 场景内的父容器。
5. 左树只有复合零件显示勾选框：勾选表示创建这一层复合零件，取消则提升其子项，普通零件仍参与导入。普通零件没有勾选框，不会创建成空容器；右键“排除选中零件 / 分支”控制是否参与导入，“恢复纳入”恢复该对象。来源装配根默认不重复建层，需要保留时勾选左树根。放到容器文字处移入；放到同级节点上沿排在其前。
6. 右侧“PS 目标树预览”随左树编辑自动刷新。容器图标表示创建复合零件，零件图标表示导入真实零件实例；悬停查看具体动作。双击或按 F2 修改场景中的容器或实例名称，不修改源 CATIA 和 JT/COJT 文件名。根节点改名同步目标根名称输入。
7. 点击“创建复合零件”可直接创建预览中的容器结构，包括空装配，不执行格式转换或零件导入。创建后可继续执行转换导入或分配已有零件，同一会话复用已创建容器。
8. 点击“转换格式并导入”，连续完成 CATPart→JT、COJT 封装、`PmPartPrototype` 设置、容器创建及实例导入归位。JT 默认不减面，保留各 CATPart 内嵌网格的三角面；取消“不减面”后才按几何及光照误差自动减面。单个零件失败记为警告并跳过，全部失败则停止。容器创建和实例导入分别形成撤销分组。
9. 分配已有零件时，在新增的 SDK 原生单对象选取框中选择一个复合零件。候选仅来自该复合零件及其下级容器中的零件，不扫描其他分支，也不回退到整个零件树。预览自动切换为分配结果：先按 CATIA 实例名匹配，再按 PartNumber 或 CATPart 文件名匹配，重名或同一 PS 实例匹配多个 CATPart 实例时提示问题并禁止分配。
10. 核对预览，排除不参与分配或无法匹配的来源后，点击“分配已有零件”。按 CATIA 编辑后的层级创建或复用本批容器，移动匹配实例并保留名称及绝对位置；范围内未匹配的 PS 零件保留原位。执行前再次核对所选范围快照，范围内容变化时必须重新检查。不再提供快速分序入口。

“重新检查”用于格式转换前重新采集 PS 目标变化；普通左树编辑无需手动检查。转换使用已读取的来源快照，直接从磁盘读取原 CATPart 的内嵌网格；读取后可切换或关闭 CATIA。需要采用 CATIA 后续修改时点击“重新读取”。转换过程中关闭窗口将请求取消，等待转换程序退出后才允许关闭；不设置固定转换超时。建树和导入期间须等待当前步骤结束。

零件级转换失败不中断本批：失败零件被跳过并列入警告，其余零件照常导入；全部零件失败时停止。转换导入失败后需核对场景并重新读取，防止重复导入。独立建树可保留无几何或转换失败实例所在的空容器。场景结果可按步骤 Ctrl+Z 撤销，转换文件不属于场景撤销范围。

## 文件、坐标与插入

### CATProduct 文件来源

来源选择“CATProduct 文件”并点击“读取 / 重新读取”，选择一个 `.CATProduct` 文件。插件仍通过正在运行的 CATIA 读取引用与实例位姿，不启动新进程，也不做离线拓扑解析：若该文件已在 CATIA 中打开则直接使用该文档，未打开时由 CATIA 打开该文件，读取完成后关闭，不保存、不修改源文档。

导入位置以所选文件根装配为基准，根装配自身位姿按单位矩阵处理，各实例位姿按文件内装配层级累计。模型目录使用该 CATProduct 文件名。该来源与“CATIA 当前文档”共用同一套预览、建树、转换、分配流程，只是读取入口和坐标基准不同；转换仍读取磁盘上的 CATPart 几何。

### 3DXML 结构与 CGR 转换

来源选择“CATIA 当前文档”并读取时，插件从活动文档的完整路径，或文件夹和文件名定位原始 3DXML。若 CATIA 将其呈现为内存产品，插件也会读取当前窗口的文件名。缺少可用路径时，在当前模式下选择一次原始文件，再通过同一预览执行“转换格式并导入”。“3DXML 文件”仍可直接选择磁盘上的包，无需 CATIA COM。

按 `Instance3D` 的父子引用恢复产品结构，按 `InstanceRep → ReferenceRep → associatedFile` 识别几何。含多个几何表示的产品显示为复合节点，各表示分别显示为子零件。实例按完整引用路径分别保存身份并累积 `RelativeMatrix`。同一包内路径只生成一份 JT，各实例按各自的装配位姿归位。

“仅转换 JT”将选中实例引用的 CGR 并行转换，在所选目录生成独立 JT。“转换格式并导入”还会封装 COJT，创建目标层级并应用实例位姿。JT 和 COJT 沿用包内 CGR 名称。遇到 `cgr10`、`cgr10_1` 等编号式名称时，优先使用关联零件的 PartNumber，其次使用实例名。同名文件使用编号后缀。转换前校验 3DXML 包的摘要，临时 CGR 在工作进程结束后清理。

通过文件头识别包内 `V5_CFV2` CGR 和 `V5_CFV3` UVR，包括用 `.3DRep` 命名的二进制资源。JT 保存三角面及 RGB，材质输出为不透明。部分 CFV 布局尚未适配。XML 网格表示、缺失资源和无法解码的项按包内路径报告，其余资源继续转换。已有零件分配仍按实例名称、零件编号或几何文件名在选定范围内匹配。

### STEP 文件

选择「STEP 文件」后读取 `.stp` 或 `.step`，无需启动 CATIA。按 STEP 产品名称预览单件及装配树，累积各实例的旋转和平移。按定义生成 JT，同一定义的多个实例共享几何。支持「仅转换 JT」和「转换格式并导入」，COJT 以零件定义名称命名。

STEP 读取器用 Open CASCADE XDE 转移产品和颜色，以毫米为单位细分曲面，绝对线性偏差为 0.05 mm，角度偏差为 0.20 rad。「不减面」保留细分结果，取消后使用现有自动减面。JT 使用三角网格、法向及零件定义或面颜色。STEP 装配需保存在一个自包含文件中。

部分面未生成网格时，仍转换该零件的可用几何并报告缺面数量。零件没有可用网格时，跳过引用该零件的实例。

- Windows x64 STEP 读取器随插件安装在 `CatiaPartTree/Step`。从源码构建时，使用 [Open CASCADE 7.9.2 SDK 与运行依赖](https://github.com/Open-Cascade-SAS/OCCT/releases/tag/V7_9_2)。将 `OpenCASCADE_DIR` 指向 SDK 的 `cmake` 目录，将 `STEP_RUNTIME_DIRS` 设置为第三方 DLL 目录和 x64 MSVC CRT 目录的分号分隔列表。
- 用 CMake 构建 `CatiaPartTree/Step`，将 Release 安装到同级 `TxTools.Local/build/bin/StepReader/Release`。运行 `tools/Build.ps1` 时会将已构建的 STEP 读取器与运行依赖复制到插件输出目录。

### 模型保存与导入

- 默认模型路径为当前 PS 系统库中名称含 `product` 的文件夹（优先精确 `product`，否则取名称最短的匹配项；未存在时在转换阶段创建 `product`），勾选“以 CATIA 文档名建子文件夹”时再追加 `<CATIA 文档名>`，其下为 `<源零件文件名>.cojt/<源零件文件名>.jt`（同名冲突时目录与 JT 同步追加 `_2`、`_3`… 序号），附带 SDK 生成的 `TuneData.xml`。文档名及源零件文件名均去掉原扩展名并保留原始中文、空格及大小写；场景实例名与模型文件名相互独立。已导入场景依赖这些文件，不能作为临时文件删除。
- 同名不同来源或重复转换遇到已有 COJT 时，直接在保存目录内为 COJT 目录名追加 `_2`、`_3`… 序号，包内 JT 使用与目录相同的名称；不建立额外子文件夹，也不覆盖已有模型及原型记录。预览及修改保存路径不会创建目录，格式转换时才实际建立目录。
- 勾选“按层级建文件夹”（默认不勾选）时，保存目录对应本次导入的目标根容器；每个新建复合零件层按其名称建立子文件夹，COJT 放在所属复合零件的目录下。根容器下的普通零件仍直接放在保存目录；同一 CATPart 被多个层级引用时只转换一次，按首次出现的位置放置。文件夹名去除 Windows 非法字符后再使用。
- 同一 CATPart 的多个实例共享转换结果，各自保留来源节点、目标归属和独立位姿，不按文件名合并实例。几何保留 CATPart 自身坐标，CATIA 累计装配变换在 PS 实例上应用一次；重新编辑目标层级不会改变已捕获的绝对位置。
- 读取及累积变换保留 CATIA 的原始矩阵，不做正交性、单位轴长或行列式符号拦截，也不对矩阵归一化。实例变换交由 PS SDK 写入，并核对实际写入结果。
- CATProduct 使用正在运行的 CATIA 读取引用及实例位置，不依赖离线 CATProduct 拓扑解析或预制位置索引。只连接已打开的 CATIA，不启动新进程、不修改及保存源文档；指定 CATProduct 文件尚未打开时由 CATIA 临时打开并在读取后关闭。
- 来源树可读取有未保存修改或不可读的 CATPart 节点。转换使用磁盘上的几何快照，不读取未保存的几何修改；磁盘文件不可读时提示问题，可右键排除该分支继续。转换仅检查纳入导入的 CATPart 文件摘要，排除分支的文件变化不阻断转换。转换完成后使用 COJT 和已捕获的位姿，源 CAD 文件移动、修改或删除不影响后续建树与导入。后续阶段仍核对 COJT、原型及 PS 工程生命周期。
- CATIA 目标节点始终按本批新建对象的 ID 管理，同名节点不会按名称合并或覆盖已有对象；最终名称是否可用由 SDK 创建结果决定。目标容器新增无关子项不阻断本批任务；本批容器失效、改名或移动仍需处理。
- 插入使用 CrossEnvIO `ComponentIO.LoadCojts`，逐件调用 PS SDK `InsertComponent` 并复用 `LibraryInsertion` 的中文路径兼容，再由 `LibraryPersistence` 核对正式库引用。SDK 接收真实最终库路径，不创建 ASCII 别名或修改系统库根；不自动另存为或重载工程。
- 插入兼容性仅在导入阶段检查，不作为 JT/COJT 格式转换及建树的前置条件。
- 原型数据复用 CrossEnvIO `DevicePrototypes.CreateTargetData`，明确写入 `Type=PmPartPrototype`、`Family=PartPrototype` 及新 ExternalID，再由 SDK 保存到当前工程的 TuneData 记录；不调用依赖当前工程规划类型表的 `CreatePrototypeData`。
- COJT 加载阶段连续调用 PS SDK 的 `InsertComponent`，收集返回对象和错误。整批加载结束后统一核对正式库引用，再通过 `AddObjects` 将同一目标容器的实例成批归位，核对名称、父级、位姿和顺序。PS 新建子节点可能排在最前，子节点顺序经 SDK `ITxOrderedObjectCollection` 调整回预览顺序；无法调整时保留已导入结果并列为待核对项，不中断本批。单件加载异常保留结果待核对。导入结果按已归位、已插入待核对、未插入统计。平移按 0.001 mm 判断，姿态矩阵按最大分量偏差 1e-6 判断。未插入任何实例或中文路径兼容层被禁用时停止。
- PS 的 `CreateCompoundPart` / `CreateCompoundResource` / `AddObject` 只写托管 `Collection`，对象树按原生对象库的树关系建层，因此 API 新建的层级会平铺在 Parts / Resources 根下（层级数据本身正确，视口选中也无法在树中定位）。建树阶段完成容器后、导入阶段实例归位后，分别用 `ITxObjectCollection.Paste` 把整棵子树复制一次并删除原对象：`Paste` 会写入原生树关系，副本保留任意深度的层级和子节点名称，顶层按预览名恢复；容器在导入阶段保持身份不变。实例副本重新核对正式库引用后才能计为已归位。`Paste` 不可用或失败时保留原层级并记为警告，导入不中断。
- 插件先以 `--protocol` 查询实际部署的转换器；`TxTools.CatiaConverter/2` 支持 `quality` 自动优化。未确认此接口的旧转换器使用原有“源 CATPart、目标 JT、源 SHA256”三参数调用，并提示同时更新插件和转换器。只有不执行转换的接口查询限时 5 秒；实际 JT 转换不设固定超时。
- 格式转换直接启动独立转换器读取原 CATPart，不调用 CATIA 打开、导出或保存文档，不复制临时 CATPart，也不调整 CATIA 显示设置。进度区显示接口查询、实际减面模式、JT 写入及 COJT 原型设置，等待期间每秒更新耗时。转换进程日志位于 `%LOCALAPPDATA%/TxTools/Logs/CatiaImport/`，记录实际转换器路径与 SHA256、进程 ID、等待及输出；日志实时刷盘，界面显示当前日志路径。转换器的标准输出包含 `timing` 与 `simplify-profile` 两行分阶段耗时：读取、减面、写出，以及减面内部各校验门的尝试次数、拒绝计数与累计毫秒，用于定位大型零件的耗时构成。
- CGR 图元描述符的 `0x08` 位表示整个图元域使用统一法向，优先于顶点法向流；在同一坐标属于不同法向域时拆分着色顶点，保留原三角形、颜色和绕向。其余域读取 4 bit 主轴码及两个 int16 分量，码 6–11 表示 ±X/±Y/±Z。无可用法向的叶使用几何回退，不丢弃其他叶已解析的法向。
- PS 转换默认使用“源 CATPart、目标 JT、源 SHA256”三参数，保留 CATPart 可视化缓存已有的采样精度和面数（不减面默认勾选）。取消勾选后才传入 `quality` 自动优化，不设体积或面数目标；孔壁和孔口仍由离散三角网格表示。两种模式使用相同的 JT 写入与压缩流程。`mesh=<CGR 路径>` 和 `meshhash=<SHA256>` 仅用于离线诊断时传入已有 CGR 文件，仍保留原 CATPart 名称、来源摘要及坐标。诊断参数 `flat` 使用逐三角形条带，不改变三角形、绕向或角点法向；`targetkb=N` 与 `simplify=N` 仅用于体积及面数对照试验。
- JT 场景图采用 `Partition → 文档 MetaData → 实体 MetaData → Root MetaData → Part → RangeLOD`。单色零件的 `Shape` 直接挂在 `RangeLOD` 下，多色零件以一个 `Group` 收纳同一 LOD 中的所有颜色形状。各形状引用材质节点和内嵌的三角网格段（类型 7）。文档节点通过 `JT_LLPROP_METADATA` 引用元数据段（类型 4），其中 `JT_PROP_ORIGINATING_BREPTYPE=None` 声明该文件为网格表示。根分区累计下属节点、顶点记录和三角形数量。
- 对完整解析原生法向绑定的网格，自动减面完成后从源曲面回采样法向。通过源边弦一致性检查的 CAD 角点使用原始解码法向，其他角点保留几何回退；最近表面超过 0.5 mm 或法向超出存储面安全范围时保留减面法向。此步骤保持全部输出三角形与位置，避免局部扇区重建再次污染已有的平面法向。

## 减面与拓扑保持

`MeshSimplify` 使用边塌陷 QEM，几何拓扑与着色顶点分别处理：

- 面颜色分界上的顶点保持固定，避免减面移动颜色边界或吞掉小色块；同色区域内部仍按几何与光照误差优化。边界候选不进入优先队列，减少无法塌陷的候选开销。颜色频繁交错的模型可减面空间较小。
- 源面夹角超过 30° 的锐边端点保持固定，包括闭合薄壁厚度面的两条轮廓。仅保持流形拓扑或增加锐边 QEM 权重不足以保持这类窄面的形状；固定原轮廓可避免两侧独立简化形成不一致的弦线和楔形折边，曲面内部仍可减面。
- 自动减面后对闭合内圆柱孔执行独立的成对孔口简化。仅处理同轴同径、顶点可轴向配对、孔壁完整、相邻面共面且同色的圆孔；两圈同步塌陷对应边，保留原坐标，不投影或修改拟合孔径。圆弧采样误差上限为 `min(0.1 mm, 几何预算 × 0.2)`，每圈至少保留 12 个顶点；局部翻面、重复面或边流形性改变时拒绝该次塌陷。不匹配的孔、椭圆、锥孔及开口孔保留原网格。圆孔识别与 PS 实际捕捉分别验证，网格拟合成功不代表宿主捕捉已经通过。
- JT 默认材质使用环境光系数 0.3、镜面反射系数 0.8、高光指数 15；漫反射继续采用原面颜色，透明度保持不透明。
- JT 写入前按实际 float32 坐标及法向精确合并重复记录，使曲面片拆点能够连接为长条带；不同硬边法向与缺失法向的记录保持独立，不做有损法向量化。三角形角点的存储坐标、法向、绕向与面颜色保持不变。
- JT 写入器还按条带中心的三维 Morton 顺序尝试排列完整条带，使邻近记录进入 DEFLATE 滑动窗口；比较原顺序与空间顺序的压缩大小，仅采用更小的结果。条带内部顺序及角点字节不变，`flat` 诊断模式保留原有逐面顺序。
- `MeshShape.Bake` 烘焙仿射变换时使用逆转置矩阵变换法向，支持非均匀缩放及剪切；镜像时只翻转三角形绕向，不额外反转法向。生产导入仍保留零件自身坐标，通过 PS 实例应用装配位姿。

- 仅合并坐标完全相同的顶点，恢复 CATIA 因法向或曲面片拆点形成的几何邻接。不同坐标的短边端点不做距离焊接，避免薄壁、针形面或相邻面层被误合并。
- 诊断参数传入的 CGR 网格仅清理与主体共一条边的反向重合双面片：其两条独立边各被该对三角形使用两次，连接主体的边被使用四次。此类零厚度附片删除后恢复主体邻接；不按长宽比删除细长面，不对邻近坐标进行焊接。
- 每次塌陷只删除共享的两个三角形，并模拟邻面索引及边使用次数变化，拒绝重复面、新开口与非流形边。真实开口和非流形边的端点固定，不以收缩孔口或删除薄壁强凑目标面数。
- 先在当前塌陷边段上解析最小化二次误差，再尝试投影到最近源曲面，投影偏移不超过该边长的 1/4；投影沿用同一套邻面折叠及累计面方向约束，不通过时回退至段内落点。误差平面使用模型包围盒中心作为局部原点，降低大坐标下的二次型消减误差。每轮减面先将累计面方向变化限制在该轮输入面的 15° 内；候选耗尽仍超过目标时才放宽至 30°，真实边界仍固定。超过 30° 的原始折角添加权重为 10 的特征误差平面。根据源法向沿边的变化量估计曲率，为小圆角和凸台追加最多 16 倍基础平面权重，在相同面数预算下优先保留这些细节；尺度采用模型对角线的 2%。细长三角形不因统一长宽比阈值被拒绝。
- 在原始网格中识别具有二维支撑的连通平面区域，同时检查位置共面性与包括边界角点在内的完整源法向场；仅有共面的粗圆弧三角形不作为平面。用于修复不一致法向的平面锚点须来自通过一致性检查的原始缓存，几何回退重建的法向不能反过来证明自身所在面片是 CAD 平面。整体稳定的缓存法向允许修复圆角邻接造成的扇区混合。狭长区域还按坐标精度和宽度判断能否解析 0.01° 的面方向；几何无法可靠定向时，只有同时与全部位置相容的稳定源法向才用于定向。平面内部的塌陷落点投回原平面，输出角点使用统一平面法向，避免周边圆角法向扩散到平面或将曲面强制改成小平面。平面与曲面的交界仅沿已有边界收缩，并校验整条原始边界路径的偏差；分叉点及不满足条件的交界保持固定。
- 输出重新按角点法向拆分着色顶点。以最终 JT 的 float32 坐标计算面方向，沿共享边将夹角不超过 30° 的邻面组织为连通平滑扇区，同一顶点的同一扇区共享法向。源网格先以角点夹角权重重建平滑法向场；缓存法向须在扇区内一致、偏离源面不超过 60°，且每条边的端点平均法向与边弦近似正交（容许 5° 偏差）。该检查兼容粗圆弧的合法端点法向，不一致时重算法向，不拒绝文件。
- 减面后通过源三角形 AABB 层次索引，在原始连通实体内查询最近曲面点，按重心坐标插值源法向，将真实曲率传递到输出扇区，避免仅依赖粗三角形重算法向形成光照分块。法向查询使用舍入前的最终顶点位置，防止 float32 坐标舍入把细圆角切线点推向相邻曲面；面方向及法向安全范围仍按实际存储的 float32 几何校验。先选几何最近点，再校验法向；方向不匹配时只在 float32 坐标舍入半径内消解硬边歧义，不按法向条件改采远处表面，也不跨相邻独立实体。传递结果与参考方向及输出扇区所有面夹角不超过 60°；不同方向的孔壁、薄壁另一侧和硬边分别处理。该范围仅用于经过源曲面验证的法向；粗网格回退重算仍使用 30° 平滑范围。真实曲面的合法角点法向可能偏离粗三角形面方向超过 30°，不能统一裁剪成粗面法向。
- 转换直接读取磁盘中的原始 CATPart，不启动 CATIA 导出或生成临时 CATPart。边索引采用混合哈希，候选边按端点版本去重；未变化的面片保留原有光照场。最近曲面查询复用上次精确结果作为上界，仍搜索完整 AABB 索引。
- `quality` 在新三角形的中心、三个边中点及三个偏心内点比较源法向与角点插值法向，误差超过 1° 时保留局部采样，避免长圆角、低起伏过渡在中心匹配时仍沿三角边出现明暗分段。生产查看模式的几何距离预算为 0.5 mm，并以 float32 坐标舍入精度为下限。既检查候选顶点及上述七个位置到源曲面的距离，也累积保存原始顶点与面中心采样，检查它们到更新后三角形的距离，避免沿源表面滑动而吞掉窄条或外轮廓。该预算限制局部采样误差，不作为源文件准入条件，也不等同于整个连续曲面的严格 Hausdorff 上界。
- 平面相邻曲面仍独立采样，仅对已近似相切的输出法向做精确对齐。生产模式在误差与拓扑允许范围内持续塌陷，候选耗尽即停止，不通过提高误差或反复追逐文件体积来强凑面数。显式面数诊断模式使用 12° 插值法向预算和随目标面数变化的几何预算；逐级放宽折痕角度时，每次从全量输入重新计算，避免在已减面网格上重新识别出虚假的平面或丢失原始法向场。JT 写入仍检查 float32 存储后是否出现退化面。

覆盖比较应使用全量模型固定相机并统计所有颜色片，分别报告漏覆盖与多覆盖像素；模型各自自动适配视口会改变投影比例，不能用于逐像素质量比较。拓扑统计按几何位置合并着色拆点，条带对照按循环旋转等价的有向角点多重集比较，保留对绕向与法向的检查。

## PS 已有零件整理

来源选择“PS 零件分支”，用原生单对象选取框选择来源与目标；选择仅创建容器或同时归类现有零件。左树编辑和右侧预览实时联动。核对后点击“执行整理”。现有同名 CompoundPart 按公共结构引擎的规则复用，零件按对象身份归类。执行后可继续快速分序。

窗口宽度限制为 650 个逻辑像素，默认高度 900 个逻辑像素；单对象采用 SDK 原生单选控件及带标题边框，左右树等宽等高并占用主要高度。两树优先通过 SDK `TxImageProvider.GetImageByPlanningType` 取得 PS 原生复合零件和零件图标；宿主不提供对应图标时使用组合方块与单方块的图形图标，不绘制文字图标。树节点保留原名，排除状态以灰色及悬停提示说明。CATIA 来源不显示 PS 来源拾取框。

## 构建与限制

通过 `tools/Build.ps1` 构建。独立 x64/.NET Framework 4.8 转换程序位于部署目录 `CatiaPartTree/TxTools.CatiaConverter.exe`，需与插件一同部署。不同 CATPart 由后台线程调度独立转换进程并行执行；并发数为不同源文件数与逻辑 CPU 数的较小值，大型零件同时转换时内存占用随并发数增加。同一源文件的多个实例共享一份转换结果。目标路径在启动前统一分配，单文件失败不阻断其他文件；界面显示已完成数量及当前文件日志。取消时停止排队任务并等待活动转换进程退出。JT 批量完成后，COJT 原型写入及其他 PS SDK 调用保留在宿主线程。

转换器支持已有适配的 CATPart 内嵌 CGR 网格布局；不支持的缓存分支、缺失几何或退化面按零件给出警告并跳过，不再中断整批。容器层失败会报告文件大小、头部目录偏移与长度、尾部 `CB__END` 状态及嵌套 `V5_CFV2` 数量，用于区分文件截断、目录后附加数据与未适配的目录版本；目录按尾部 `CB__END` 记录或头部目录字定位，`CATIA_V5 CBxxxx` 版本号不作为拒绝条件。分配表的 extent 数据允许位于目录块之后（零件可在目录后继续写命名流段，如 `FINJPL`），只按文件边界校验。单叶缓存可用一个网格叶容纳整个零件，顶点数上限按格式整数范围放宽，索引宽度随顶点数取 1/2/3 字节。坐标位图每顶点 2 bit：0 为完整 XYZ、1 完全复用、2 只写 Z、3 写 Y/Z；首顶点从零点开始复用，因此允许以 2/3 开头（STP 直接保存的平板常以前表面 X=0 起始），并逐叶核对位图与坐标值数量。流内与叶头不符的标记字节按坐标数据噪声跳过，不因此否定已解析的叶。面颜色记录的样式字节 `0x20`/`0x30` 共用同一 RGB 布局，图元 transition 变体 2–5 共用同一框架。缓存中确实没有三角网格的零件会明确提示需要先在 CATIA 中更新缓存，而不是报告为格式错误。不设置试验性网格数量、坐标绝对值或 0.001 mm 舍入阈值，仍检查文件边界、有效索引、有限数值及 JT 存储后是否退化。大模型受进程可用内存及格式自身的整数范围限制。JT 为毫米制三角网格，按 float32 存储坐标，保留已有转换内核的面颜色及几何法向，不包含参数特征或 B-Rep。暂不支持未解析引用、未保存的 CATPart 几何及在线工程；实例变换的实际支持范围由 PS SDK 决定。实际 CATIA COM 读取、COJT 加载与中文路径原生插入仍须在 CATIA/PS 宿主中验收。
