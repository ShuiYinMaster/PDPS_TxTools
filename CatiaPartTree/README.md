# CatiaPartTree

根据 CATIA Product 目录树在 Process Simulate 中创建零件树，并把已导入的零件归类到对应的 `CompoundPart` 容器。

## 命令

- `.目录树建零件树`

## 功能

- 读取 CATIA 产品目录树并显示为可编辑的层级结构。
- 支持选择 PS 中的目标父容器，或按 CATIA 层级自动定位/创建容器。
- 可选择是否包含根节点、是否优先使用 `PartNumber` 作为名称。
- 可选为叶子零件创建空集，或跳过叶子容器。
- 将未匹配的已导入零件放入“未分类”容器。
- 建树后可保存并重载文档，以刷新 PS 树和对象引用。

## 基本用法

1. 启动 `.目录树建零件树`。
2. 读取 CATIA 目录树，检查节点数量和勾选范围。
3. 编辑节点名称、包含状态及目标父容器。
4. 设置根节点、`PartNumber`、叶子容器、自动建容器和重载选项。
5. 执行创建/归类，并根据日志检查未匹配或失败项。

## 注意事项

- CATIA 读取使用 CATIA COM；CATIA 必须已启动且当前产品可访问。
- 创建零件树和归类会修改 PS 场景，建议先保存文档并确认目标容器。
- 目录树名称相同或存在特殊字符时，应结合日志和 PS 树复核结果。

## 主要文件

- `CatiaPartTreeCmd.cs`：PS 命令入口。
- `CatiaPartTreeForm.cs`：读取、编辑和执行界面。
- `Core/`：CATIA 树模型和读取逻辑。
- `Ps/`：PS `CompoundPart` 创建、归类和重载逻辑。
