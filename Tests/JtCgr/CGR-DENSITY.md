# R55 CGR 显示细分密度（2026-10-12）

版本：`CGR-20261012-R55-adaptive-cylinder-density`。正式 TxTools 源码已同步并编译到指定生产 bin。

参考文件为用户提供的 CATIA 输出 `FFM170-X-1266-CLOSE-A2-2025.08.05.cgr`。
仅对该参考文件进行了读取分析；未对我们生成的 CGR 执行独立回读。
参考文件与验证 JT 是不同焊钳型号，不能以两者文件大小之比作为压缩改善率。

参考文件的 77 个显示叶块包含 45274 个坐标、76098 个非退化三角形、4211 个面域，
其中 1405 个面包采用恒定法向。分析器校验坐标数值数量、包索引数量及索引范围。
在各叶块的局部坐标中拟合到 629 段圆柱，多数端环为 8～16 点，最大观察到 46 点。
显示容差字段为 0.2。该数字是读取到的字段，不等同于每个曲面的实测最大弦高。
本轮没有完整解释该文件的全部测量属性布局；生产的圆柱/圆边属性仍沿用此前已对照
CATIA 原生圆柱探针的编码，不从显示分段数推导测量精度。

原生产设置对普通圆周强制至少 96 段，弦高目标 0.002 mm。R55 默认改为：

- 普通圆柱按半径计算分段，至少 24 段、目标弦高 0.02 mm；保留全部原端环角度，避免破坏原接缝。
- 复杂裁剪端口仍沿用 96 段下限与 0.002 mm 保护；带横向孔的联合约束细分保持原严格限制。
- 中心、轴向、半径、深度、原生圆柱/圆边属性写法不变，原材质和透明度不变。
- API 保留原四参数调用；第五参数可显式传入 `RoundHoleCgrMesh.DisplayOptions.Fine()` 使用旧的精细设置。
- 法向和显示块编码使用已验证的原写法。面级恒定法向试验未通过本机 CATIA 导入并导致异常退出，已撤回；不是最终版本的一部分。
