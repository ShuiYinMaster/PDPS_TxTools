# R44 七个夹具 JT 的兼容分析与验证（2026-10-10）

正式版本 `CGR-20261010-R44-jt8-strips`；worker 标识 `jt8.0-10.0-10.6-rgba-v8`。已直接修改 TxTools 并编译到指定生产 bin；不依赖 Python。七个样本通过直接 JT→CGR→CATIA 验证，没有使用 PS 几何回退。

## 实际差异与修复

1. 5156 为小端 JT 10.0，其他六个为小端 JT 8.0。旧版本只允许 JT 10.6，因此七个输入均在版本检查处退出。
2. JT 10.0 使用 Base Attribute v1 的 89 字节材质体；10.6 的 v2 为 93 字节，多出尾部 Palette Index。正式解析同时接受这两种明确布局，按文件实际版本初始化几何读取器，不再硬写 10.6。
3. 5156 有 225 个 Shape 在自身及祖先节点上均无漫反射 RGB。保留所有已有颜色，仅对最终未定义 RGB 使用应用默认中性灰 `204,204,204`，并逐项写 `MATERIAL_DEFAULT` 日志。这是应用显示策略，不是从文件恢复出的原始颜色，也不宣称是 JT 规范指定的默认颜色。
4. JT 8.0 使用 32 位 TOC 偏移、记录体中的对象 ID、zlib 场景图和无损三角带。新增独立 JT8 分支，通过现有纯托管参考读取器读取这些容器，转换为共同的场景数据，再执行材质继承、最高细节 LOD 选择、刚体变换和 RGBA CGR 写入。三角带交替绕序及多个资源实例均保留。
5. JT8 漫反射 RGB/Alpha 的 Field Inhibit 位不同于 JT10，旧式 Final 状态位也单独映射。六个文件中的 `RGB=-1,-1,-1` 被作为未定义颜色记录处理：不覆盖继承 RGB；已有祖先颜色因此保留。其他不合法颜色仍报错。

Base Attribute v1/v2 及继承、Force/Final 语义参考 [ProSTEP JT 格式说明](https://www.prostep.org/fileadmin/prod-pay-download-8c1d/JTIAP_V3_Format_Description_and_annexs.pdf)，实现也核对了项目内参考读取器的对应分支。

## 验证入口与支持范围

`SampleRegression.cs` 参数为源 JT、全新输出目录、正式 bin。它执行正式 ConvertToCgr 并逐三角面回读比较，不要求样本一定含透明材质。`SampleBatch.cs` 参数为七个文件所在 COJT 父目录、全新批量输出目录、正式 bin，启动最多两个独立 C# 验证进程。它只选择上述七个编号，不包含父目录里的其他资源。

本次验证的 JT8 路线支持无量化坐标、无纹理/顶点色、无损三角带，以及无法向或逐顶点法向绑定。其他布局仍明确拒绝；不能据此承诺任意 JT8、JT9、大端文件或其他 JT10 小版本都已兼容。原版本、几何和文件来源校验继续保留，未关闭对未引用最高细节段、非刚体/镜像变换及非法数据的检查。

详细日志、summary.json、CGR、CATProduct 和截图位于本机工作区 `jig_batch_r44`，不随源码提交客户 JT 或测试模型。现场需重新加载插件，使 DLL 与解码 worker 同时采用 R44。
