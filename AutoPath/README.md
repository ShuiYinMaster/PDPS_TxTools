# 自动路径规划

在选定的焊接操作中准备 home、进枪、出枪和过渡位置，基于 Process Simulate SDK 验证机器人及外部轴运动。规划、SDK 调用及场景写入均在主线程执行。

## 规划流程

1. 根据操作绑定解析机器人，以对象 ID 区分同名实例；只读附着已有干涉集。
2. 按源点工具定义设置 TCP；完整位姿逆解经正向运动学核实后选用，位置误差不超过 1 mm，姿态误差不超过 0.5 度。
3. 计算进出枪偏移，创建或更新准备点，核实 Config、焊钳开口及实际执行顺序为“进枪—焊点—出枪”。home 保留原始关节姿态。
4. 自由转移段采用联合关节空间 RRT-Connect。状态由机器人驱动关节及两端声明的外部轴实际值组成；旋转值保持实际圈数，不在搜索中归一化。
5. 每条树边、连接、捷径调用关节扫掠验证。搜索节点直接转换为带关节解、Config、TCP 完整位姿和外部轴值的位置，不重新通过笛卡尔位置选解。
6. 失败连接保留缺口，其他独立连接继续。每段写入后按实际操作树中的点序执行终验，通过的分段单独保留。
7. 完整路径尚未通过时，操作描述保留 PreparedOnly 标记。单点或独立分段通过均不代表整个操作可连续执行。

## 关节与外部轴

机器人关节以 SDK TxPoseData 单位存储：旋转为弧度，直线轴为长度单位。焊钳到达与离开外部轴分别处理，其他外部轴按设备和关节 ID 匹配，不按名称合并。段两端声明的外部轴集合必须一致；缺失或不完整时报告该段不可验证。

查询和搜索会临时摆位；结束、失败或取消时恢复机器人和外部轴状态。写入后的 Config、到达与离开外部轴均读回核实。写入后终验始终检查碰撞，不随可选的动态修复开关关闭。

焊钳开口影响实际碰撞包络。焊点到达及离开开口单独设置，默认 0 mm（CLOSE 位姿），可按工件厚度调整；进出枪默认 30 mm，必须大于焊点开口。两种开口均写入外部轴并读回，保留无关轴各自的到达及离开值。

自由转移优先固定两端小开口，失败后依次放宽到 60 mm、120 mm 和物理最大开口；所有阶段共享单段查询及时间预算，小开口阶段分配 40% 搜索时间，其余阶段共享 60%。两端开口大于阶段上限时保留实际端点值。非焊钳外部轴两端值相同时锁定该轴。中间位置保存实际采用的开口，写入时不得替换为另一默认开口。毫米开口自动换算支持已注册的直线焊钳轴；旋转焊钳需要开口与角度标定。

六旋转轴机器人收集各焊点完整逆解及限位内 J4、J6 等价圈数，通过整条焊点序列的动态规划兼顾腕部居中与实际轴值连续性。相邻 TCP 位移和姿态变化较大的转移段降低回腕代价，使必要换圈优先在这些转移中完成；焊点重排后重新选解。源点保留肩肘及 Overhead 约束，允许比较腕部分支与有效圈数；改选后记录完整 Config。进出枪偏移搜索以对应焊点的已选关节解为参考，优先保持相邻分支及圈数，写入时复用该关节解。

大角度自由转移会尝试腕部居中的中继关节状态，并引导后续关节树采样。候选中继、连边、平滑均接受同一套限位和碰撞扫掠验证；中继不保证存在可行连接，也不改变焊点要求的 TCP 位姿。

SDK Overhead 构型、无效关节值及硬限位余量内姿态被拒绝。旋转轴硬余量默认 1 度；靠近限位 5 度以内、标准六轴腕部距奇异区 10 度以内增加选解代价。大关节行程继续执行完整扫掠，不仅凭行程跨度认定翻转。

## 碰撞集

检测方包含机器人安装总成；底座依据附着关系及机器人坐标下方的几何候选识别，不依赖名称。其他机器人、工具和底座默认保留为障碍。安装接触仅对确认的对象对、固定位置和小接触容差生效，基线只用于诊断。

规划期间仅启用当前使用的干涉集，并恢复原启用状态、碰撞总开关与查询模式。已有集合只读复用，不重写用户成员。插件拥有的自动集合可预览成员差异后更新。

## 参数

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 关节扩展步长 | 12 度 | 旋转轴扩展尺度 |
| 直线轴扩展步长 | 25 mm | 直线外部轴扩展尺度 |
| 全局采样占比 | 30% | 全限位采样比例，其余偏向两端关节走廊 |
| 关节树节点预算 | 1200 | 每个开口阶段的两树节点总量上限 |
| 单段搜索时间 | 25 秒 | 搜索时间预算 |
| 单段查询预算 | 7000 | 状态与碰撞查询预算 |
| 扫掠步数上限 | 256 | 超出后标为未验证，不降低采样精度 |

单段还包含状态回放及验证开销，SDK 单次调用不可中断，因此时间预算不是严格实时上限。动态修复默认单次最多 8 秒、500 个树节点。迭代、无生长和节点预算均可结束未连通搜索；搜索失败只表示本次未找到路径。

## 分段保留与重复运行

准备点以来源焊点 ID 和类型标记归属，重复运行更新同一准备点。准备阶段提交后，后续失败不撤回这些点。未完成准备阶段的新点会清理。

通过实际轨迹终验的新分段独立保留。当前分段失败或取消只清理其未提交过渡点，不删除此前已通过分段。界面分别报告准备点数量、独立连接通过/失败数量和未连通段。操作中预先存在的其他 Via 也纳入所在区间的实际点序终验。

## 实现与验证范围

- CollisionSetService.cs：资源归属、接触规则、集合复用与隔离。
- CollisionWorld.cs：SDK 摆位、Config、联合关节状态、运动验证与恢复。
- RrtPlanner.cs：JointRrtPlanner 联合关节空间搜索；保留旧纯几何规划器供兼容调用。
- GunAxisService.cs：活动焊钳解析、开口换算、外部轴写入与读回。
- WeldPathPlanner.cs：准备点、分段搜索、修复、写入和结果管理。

SDK 运动验证采用关节与外部轴的离散插值，只能核实受支持的 Joint/PTP 运动；非 Joint 运动报告未验证。离散碰撞检查不能等同于连续碰撞检测，也不能替代机器人控制器、RCS 插补及实际工作站的验证。其他机器人的碰撞几何按当前场景姿态参与，未实现多机器人时间协同规划。

使用 tools/Build.ps1 构建，输出和中间文件位于同级 TxTools.Local/build。正式测试位于同级 TxTools.Local/tests/AutoPath。
