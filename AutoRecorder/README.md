# AutoRecorder

Process Simulate 操作录像插件，用于把选定操作的仿真过程批量录制为视频。

## 命令

- `.操作录像`

## 功能

- 在 PS 主视口或操作树中拾取一个或多个操作，按顺序逐个录制。
- 每个操作生成一个视频文件，默认使用 H.264/MPEG-4 AVC 编码。
- 可设置帧率、压缩质量和自定义分辨率。
- 支持为操作记录起始视角，并按 Location 设置关键帧视角。
- 可在录制前自动把视角聚焦到当前操作。
- 支持使用 FFmpeg 对生成的视频进行加速处理。

## 基本用法

1. 在 PS 中点击 `.操作录像`。
2. 在主视口拾取操作，可重复拾取以形成批处理列表。
3. 选择输出目录或文件名，按需设置编码、分辨率和视角。
4. 点击开始录制，观察窗口中的任务进度与日志。

如果需要固定起始镜头，可先在 PS 中调整视角，再使用“记录当前视角为起始”或操作对应的“设定为当前视角”。

## 注意事项

- 录制依赖 PS 的仿真播放器和电影录制接口；当前文档/版本不支持的操作类型可能无法生成有效视频。
- 使用 FFmpeg 加速时需要提供可执行文件路径，输出文件应先确认可写。
- 批量录制会逐个改变仿真播放和视角，执行前建议保存当前场景。

## 主要文件

- `AutoRecorderCmd.cs`：PS 命令入口。
- `AutoRecorderForm.cs`：操作列表、参数和视角设置界面。
- `RecordingService.cs`：录制队列、播放器、相机关键帧和输出流程。
- `PsReader.cs`：PS 对象与点位信息读取辅助。
