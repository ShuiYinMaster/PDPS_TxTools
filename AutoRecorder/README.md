# AutoRecorder — Process Simulate Video Recording / 仿真录屏

Record selected Process Simulate operations as videos, with configurable views, resolution and encoding.

Process Simulate 操作录像插件，用于把选定操作的仿真过程批量录制为视频。

## 命令

- `.操作录像`

## 功能

- 在 PS 主视口或操作树中拾取一个或多个操作，按顺序逐个录制。
- 每个操作生成一个视频文件，默认使用 H.264/MPEG-4 AVC 编码。
- 可设置帧率、压缩质量和自定义分辨率。
- 支持为操作记录起始视角，并按 Location 设置关键帧视角。
- 每个操作可独立编排定点、环绕焦点、推拉和两点移动镜头。
- 镜头支持仿真时间、到达 Location、上一镜头结束三种开始条件。
- 可在录制前自动把视角聚焦到当前操作。
- 支持使用 FFmpeg 对生成的视频进行加速处理。

## 基本用法

1. 在 PS 中点击 `.操作录像`。
2. 在主视口拾取操作，可重复拾取以形成批处理列表。
3. 选择输出目录或文件名，按需设置编码、分辨率和视角。
4. 点击开始录制，观察窗口中的任务进度与日志。

新操作默认使用“快速录像”：选择操作和输出位置即可录制，不应用保存的镜头编排。需要相机运动时，选择镜头类型并添加，自动进入“编排镜头”。切换录像方式保留已有配置。

## 镜头编排

窗口按操作顺序分为三列：左侧原生多选操作，中间录像方式、镜头列表、路径及时间范围，右侧设置选中镜头。选择类型后添加镜头，设置持续时长并记录当前 PS 主视口的起始视角；两点移动还需要记录结束视角。环绕和推拉默认使用对象焦点。镜头默认按顺序衔接：首个启用镜头从零秒开始，后续接在上一个启用镜头结束后。改变时长或通过“编辑”菜单上下移动，会改变后续顺序镜头的时间。指定仿真时间及 Location 触发保留各自条件。

输出文件、帧率和录制按钮固定在底部；编码、分辨率和输出倍速等位于“高级设置”。环绕参数默认收起，旋转角度常驻；“记录当前视角为起点”与预览按钮固定显示。

窗口默认设计尺寸为 1060×680，最小尺寸为 1000×620，实际尺寸随 DPI 和工作区调整。属性栏保持紧凑宽度，参数过多时仅在属性区滚动；原生操作选择区保留至少五行。

环绕和推拉支持原生对象单选框与原生坐标选择框。坐标按世界坐标系解释，距离单位为 mm，角度单位为度。对象焦点可保存位置快照或持续跟随对象。先选择焦点，再记录起始视角，可以初始化环绕半径、高度和起始角度；这些参数也可直接修改。旋转角度按世界旋转轴的右手规则取正负值。推拉通过相机位移改变距离，不改变视场角。

时间轴显示操作预计总时长以及可以计算开始时间的镜头，灰色区间沿用当前或上一视角。Location 及其后接续镜头在事件发生前不显示精确时间。超过预计时长、时间重叠、缺少相机、焦点无效及 Location 越界会通过“配置检查”集中列出，未完成配置的编排操作不能开始录制。操作时长由 SDK 读取，未知时按镜头估算。事件镜头触发时中断当前镜头；同一时刻后列出的镜头优先。同 Location 的新镜头优先于兼容 Location 视角。

点击时间条会选择对应镜头并按局部进度预览相机；点击灰色尾段会选择最后一个已开始镜头并保持其末态。选择列表中的镜头会定位时间条至该镜头开始位置。此交互不跳转机器人仿真进度，事件时间未知时不会显示虚假的时间点。时间条获得焦点后支持左右方向键微调、Ctrl+方向键按秒微调，以及 Home/End 定位。

镜头列表或时间条获得焦点时，Delete 删除选中镜头，Ctrl+上/下方向键调序；名称、数值输入框和原生资源选择器中的 Delete 不会删除镜头。列表支持同一操作内拖放调序，拖放时显示插入标记。顺序镜头的时间随排序重算，指定时间保持不变。外部资源和其他操作的拖放不会被解释为镜头调序；预演或录制期间锁定删除、拖放及时间条交互。

“预览选中镜头”及其进度条只改变相机，不推进仿真。路径按相机求值结果投影绘制，环绕角度、推拉距离及两点视角修改后会更新。“记录视角”同时通过 SDK 获取当前主视口缩略图；图像获取失败不影响相机参数保存。

播放工具栏按“单镜头预览、整段操作预演、暂停/继续、停止、恢复视角”排列，使用可随 DPI 缩放的矢量图标。悬停显示操作名称及影响范围，Tab 聚焦后可使用空格或回车激活；暂停时切换为继续图标。旁边显示播放范围、当前时间和暂停状态；整段预演显示操作总时长（已知时）。恢复视角仅在存在可恢复相机且未锁定编辑时启用，点击会停止单镜头预览。播放锁定期间保留属性布局并禁用编辑，避免参数行跳动。图标按钮保留紧凑尺寸，不应用文字按钮的最小宽度规则。

“预演整段操作”播放当前操作及完整镜头调度，不生成视频，支持暂停、继续及停止。如果 PS 已有仿真正在运行，则不启动预演。SDK 时间和到点回调只采集事件，由 UI 定时器合并求值并最多应用一次相机更新；相同相机不重复应用，播放更新不再强制刷新整个应用视口。预演不修改全局播放选项，也不主动改写当前操作。

停止请求先返回界面消息，由 UI 定时器执行一次原生停止；停止或自然结束后保留当前仿真位置和画面，不自动退带、重置播放器或跳转旧时间，避免同步重算与 SDK 重入。“恢复视角”单独恢复预演前相机，不恢复机器人位置。停止失败时保留会话和编辑锁定，允许重试；关闭窗口会等待停止流程完成。预演与录制共用镜头调度器；真实 PS 中的画面连续性、停止响应和录像采帧时序仍需运行验收。

“配置”菜单支持保存和载入 `.txcamera.xml`，保存当前操作的录像方式、镜头参数、视角缩略图及兼容 Location 视角，不修改场景文件。“复制到其他已选操作”作用于左侧原生选择框中的其他操作，替换前列出目标。载入或跨操作复制后，对象焦点必须用原生单选框重新拾取；不会按名称自动绑定场景对象。固定世界坐标可以保留，但应检查其适用性。明确设置的起始视角优先于自动聚焦；快速录像忽略镜头配置。

## 注意事项

- 录制依赖 PS 的仿真播放器和电影录制接口；当前文档/版本不支持的操作类型可能无法生成有效视频。
- 使用 FFmpeg 加速时需要提供可执行文件路径，输出文件应先确认可写。
- 批量录制会逐个改变仿真播放和视角，执行前建议保存当前场景。

## 主要文件

- `AutoRecorderCmd.cs`：PS 命令入口。
- `AutoRecorderForm.cs`：操作列表、参数和视角设置界面。
- `RecordingService.cs`：录制队列、播放器、相机关键帧和输出流程。
- `PsReader.cs`：PS 对象与点位信息读取辅助。
- `CameraShot.cs`：镜头模型、相机求值和调度。
- `CameraShotEditor.cs`：镜头属性、原生拾取、时间概览和相机预览。
- `TransportIconButton.cs`：播放工具栏矢量图标、焦点及交互状态绘制。
- `ShotPlan.cs`、`ViewSchedule.cs`：时间范围、配置检查和统一镜头列表。
- `ShotPreset.cs`：镜头配置文件及缩略图存储。
- `SimulationPreview.cs`：完整操作预演和会话恢复。
- `RecordingSettingsDialog.cs`：紧凑高级设置窗口。

## 界面与构建

自动录屏窗口接入 `PickAwareTxForm`。操作列表拾取中按 Esc 保留已选操作并退出拾取；录制与编码流程沿用现有实现。

本模块随 `TxTools.csproj` 构建。环境与注册方式见 [项目 README](../README.md)。

公共拾取实现位于 `SRC/PickFocus.cs` 和 `SRC/PickAwareTxForm.cs`；焦点回归位于独立测试目录。测试使用 SDK 控件替身和真实 WinForms 焦点/键盘消息，仍需在 PS 内确认实际拾取效果。

## 撤销与恢复（2026-10-07）

录制、播放、相机切换属于运行和视图状态；生成的视频文件不由 PS Ctrl+Z 删除或恢复。取消使用停止/终止接口；录制前视角及实际仿真状态应在宿主中核验。

详见 [统一撤销与恢复说明](../docs/undo-safety.md)。
