# WeldSpotGrouper — 快速分序

按零件层级、手选工序节点或绑定零件实例组合生成操作结构，将已有焊点位操作分配到新建或已有焊接操作。入口类仍为 `WeldSpotGrouperCmd`，显示名称为 `.快速分序`。

## 使用

窗口按“零件结构 → 焊点范围 → 目标操作 → 分组规则 → 预览调整 → 执行”排列。PS 对象统一由 SDK 原生拾取器输入：点击拾取行后到 PS 树或场景中选对象，Esc 结束拾取，使用网格自带删除功能移除输入。拾取框统一使用带标题和边框的分组框，按五行数据、表头和拾取行设置高度，总体窗口宽度固定为 650 个逻辑像素，三个拾取框按三等分填充，长对象名称不改变列宽；高 DPI 随窗体缩放。

1. 按零件结构分组时，在第一个拾取框选一个 PS 零件分支；从零件树整理传入草稿时可直接使用。
2. 在第二个拾取框添加焊点操作或资源分支，可多选、可重叠。
3. 在第三个拾取框选一个目标复合操作。
4. 选择分组规则。结构模式在左侧“零件树 · 勾选工序来源”直接勾选节点；层级以来源根为 0，“按层级”替换全部标记。输入就绪后以及修改左树时，250 ms 后自动刷新。
5. 焊接操作名称直接使用来源节点的目标名称，不追加“_焊接”。右侧“操作创建预览”显示实际目标结构；唯一额外节点是“待分配（虚拟，不创建）”，集中显示未分配及决定保留原位的点。虚拟节点不参与写入，点位在分配前保留 PS 原父级。
6. 范围内点位支持 Ctrl 点击增减选择、Shift 点击连续选择、Ctrl+A 全选；多选同步到 PS 当前选择。右击已选点保持整组选中状态。
7. 右击焊点选择“将焊点分配至”，子菜单按当前工序动态更新，包含新规划工序、已有目标焊接操作及虚拟待分配操作。批量分配至工序时追加到末尾；分配至虚拟操作表示保留原位。右键也可新建接收所选点的工序、恢复自动归属或撤销点位调整。
8. 可将一组点拖到另一工序，也可直接拖到其他焊点上：上半部插到它之前，下半部插到它之后，蓝线显示落点。批次保持预览中的相对顺序，同工序内也可调整点序。拖到虚拟操作或其中点位仅调整待分配归属和显示顺序，不生成真实操作。
9. 拖动时停留在上下边缘持续滚动，悬停折叠工序可展开，离开、放下或取消后停止。工序之间拖动调整工序顺序；点位归属和点序由同一个撤销动作恢复，重新扫描保留有效人工调整。
10. 手工分配后的绑定零件签名若不在目标工序自动匹配的签名集合内，点位标红，悬停或选择可查看不一致原因。标记不改变实际名称或焊点零件绑定。
11. “重新扫描场景”用于 PS 外部的点位范围、对象或绑定变化；普通窗口编辑自动更新。执行前校验快照，执行后核对目标树的对象、名称、工序顺序和点位顺序。虚拟操作始终排除在验证与写入结构之外。

## 规则

- 默认使用零件实际对象身份；CATIA 来源仅允许唯一的原始名称/PartNumber 匹配；同一叶子对应多个 PS 实例时，相关点统一待分配，需明确实例绑定。
- 层级分配将每个已选节点视为包含全部有效子集的零件集合；对所有绑定零件的已选祖先求交集，归入最深的公共工序。OP05 属于 OP10 时，OP05 内部点归 OP05，OP10 与 OP05 的连接点归 OP10，多层和兄弟子集按同一规则处理。明确排除的分支不参与匹配。
- 只有不存在已选公共工序的跨分支点才按跨分支策略处理。可保留原位、人工分配，或归入最近公共装配；来源根仅在明确选为工序时接收其子集连接点。
- “按绑定零件实例组合”保留组合分组方式，同名不同实例分别处理。
- 一个焊点特征关联的多个点位操作分别处理；不为没有点位操作的特征自动建点。
- 仅有实际接收点位的平级焊接工序会写入，不镜像零件装配层级创建工序组。同级唯一同名且类型正确的操作会复用，已在目标内的点不移动。

## 工艺与恢复

执行前检查活动文档、点位范围、对象结构、零件绑定和机器人/工具关联。跨操作拆分含过渡点的源操作会被阻止；来源机器人/工具不一致或与已有目标不一致时拒绝移动。新建焊接操作继承一致的机器人和工具引用，并验证写入结果。

未手工调整时按扫描顺序排列，默认移入已有工序的点追加到末尾；人工插入点序优先，并保留其他原有子项。点位顺序调整与归属移动纳入同一个场景撤销分组；不写入仿真开始时间或生成机器人轨迹。其他继承属性、控制器参数和时序影响仍需在 PS 宿主复核。

一批写入使用一个场景撤销分组。移动后验证父级和相邻顺序；失败项尝试补偿，部分完成时需 Ctrl+Z 撤销整批。焊接操作创建不支持时报告错误，不降级为其他容器类型。

## 限制与构建

人工分配、名称、工序顺序和点位顺序保存在当前窗口的草稿中，重新扫描保留仍然有效的决定；失效目标显示为待处理，超出范围的人工决定单独提示。读取新的零件来源会重置分序草稿。当前不支持规则预设、跨会话映射恢复、自动轨迹排序。

修改输入时暂时禁止执行并自动计算预览；输入不完整或计算失败时清空预览。执行后保留本批结果及扫描时的原工序路径。没有实际变更时显示“无需变更”并禁用执行；仅顺序变化时显示“执行顺序调整”。刷新保持已有折叠状态；操作过渡点检查与对象快照在每次计算中复用，避免同一源操作按点反复扫描。执行前失败明确报告未修改场景；写入中断显示已完成数量和恢复提示。

通过 `tools/Build.ps1` 随主工程构建。分序规划与执行位于 `Core/SequencePlan.cs`，来源与目标结构共用 `SRC/TreeWorkflow.cs`。正式回归测试位于独立本地测试目录；实际移动、关联继承和撤销需在 PS 2402 验收。
