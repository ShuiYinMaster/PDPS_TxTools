# SelectButton

根据当前选中的操作或操作组，一键收集并选中焊点、过渡点或连续点；同时提供打开资源磁盘目录的快捷命令。

## 命令

- `.选中所有焊点`
- `.选中所有过渡点`
- `.选中所有连续点`
- `.打开资源所在目录`

## 选点规则

- 焊点：遍历选中操作的后代，选中焊接位置操作；可附带尝试选中 `TxWeldPoint`。
- 过渡点：选中非焊接、非连续的 `Via`、`Home`、`Arc` 等位置操作。
- 连续点：展开 `Continuous/Seam` 容器，仅选中其 `SeamLocation` 子操作，不选容器本身。
- 结果会去重后写入 PS 当前选择集。

## 使用方法

1. 在 PS 操作树、路径编辑器或视口中选中操作/操作组。
2. 点击对应的选点命令，插件会遍历后代并更新选择集。
3. 使用“打开资源所在目录”时，先选中 Component、Part、Tool 等资源；插件会用资源文件所在路径调用 Windows Explorer。

## 注意事项

- 三个选点命令以当前选择为输入；没有选中对象时不会产生结果。
- 连续点的最终选择对象是 `SeamLocation` 子操作，具体层级取决于 PS 操作树结构。
- 打开目录命令依赖对象可解析出 `StorageObject.FullPath` 或常见路径属性；同一目录只打开一次。

## 主要文件

- `SelectPointsCmds.cs`：三类点位收集、去重和选择集写入。
- `OpenResourceFolderCmd.cs`：资源路径解析和 Explorer 调用。
