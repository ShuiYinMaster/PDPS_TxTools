# ThemeTuner

运行时调整 TxTools 各插件窗体的统一配色主题，并将设置持久化到 `theme.cfg`。

## 命令

- `.主题调整`

## 功能

- 提供系统默认、冷色、浅色、琥珀金、草木绿、马卡龙和扁平无色等预设。
- 支持通过颜色块自定义主按钮、次要按钮、卡片标题、卡片底色、日志等颜色槽位。
- 实时预览标题、按钮和日志样式。
- 点击“应用并保存”后更新 `FormUiKit.Theme`、重绘已打开插件窗口并写入配置。
- 支持恢复/重置当前调色板。

## 使用方法

1. 点击 `.主题调整`。
2. 选择预设，或点击颜色块使用颜色选择器编辑关键颜色。
3. 查看预览，确认后点击“应用并保存”。
4. 重新打开插件时会继续使用持久化配置。

## 注意事项

- 预设和自定义颜色在点击“应用并保存”前只存在于当前工作调色板。
- 开启扁平风格时，部分颜色设置不会生效，但扁平风格开关仍会保存。
- 主题是 TxTools 公共 UI 状态；修改后会影响已经打开的多个插件窗口。

## 主要文件

- `ThemeTunerCmd.cs`：命令入口。
- `ThemeTunerForm.cs`：主题预设、色槽、预览和保存逻辑。
- `ThemeTunerForm.UI.cs`：窗体控件布局。
